\chapter{量子力学与路径积分}

\section{量子力学回顾}

近代光学实验中，光常同时表现出粒子和波动的性质，人们逐渐形成波粒二象性的观念，物质状态笼统地称为\textbf{量子态}(quantum state)。
量子一词起初源于黑体辐射的能量离散化、光电效应的光量子，后来延伸为波粒二象性等有悖于经典状态的性质。

经典理论中系统的物理可观测量是实数，比如单粒子的位置及动量 $\bm x,\bm p$，二者可同时测定，进而确定系统在相空间\footnote{单粒子的相空间简单讲就是全体 $(\bm x,\bm p)$ 构成的集合，系统相空间就是多个粒子相空间的集合乘法。}中的运动轨迹。但有趣的是，在量子理论中，我们无法同时观测粒子位置及动量。
Heisenberg 提出，测量值的不确定性意味着必须将物理量“提升”为一种\textbf{算符}(operator)，对物质某个性质的\textbf{测量}(measure)或\textbf{观测}(observe)，就抽象为用这个物理量算符去作用于物质的量子态。比如 Descartes 坐标系的位置和动量 $\hat{\bm x}=(\hat x_1,\hat x_2,\hat x_3),\hat{\bm p}=(\hat p_1,\hat p_2,\hat p_3)$，他根据有关不确定性的实验和研究提炼出
\eq{
    \tcbhighmath{[\hat x_i,\hat p_j]:=\hat x_i\hat p_j - \hat p_i\hat x_j = \i\hbar\delta_{ij},}\quad (\delta_{ij}) = \diag(1,1,1).
}
$\hbar=h/2\pi$ 是约化 Planck 常数。这称为 $\hat{\bm x},\hat{\bm p}$ 的\textbf{对易子}，意思无非是对量子态先作用 $\hat p_j$ 再作用 $\hat x_i$，减去其相反操作，结果相当于乘上 $\i\hbar\delta_{ij}$。
这是量子力学不可避免涉及复数的一处体现。
尽管我们仍没有说出量子态、算符的数学表示，但我们要求它们一定服从这种对易关系。
一维情形为 $[\hat x,\hat p]:=\hat x\hat p - \hat p\hat x = \i\hbar$。
经典力学是 $\hbar\to 0$ 的极限，意味着 $\hat x\hat p=\hat p\hat x$，作为普通实数的 $x,p$ 就满足这个可交换乘法。
算符的非对易性可以说是量子性质的关键，因此这种“算符提升”也称为从经典力学走向量子力学的\textbf{量子化}。
在经典力学中，$x,p$ 是一对共轭变量，也叫正则变量，满足 Poisson 括号 $\{x,p\}=1$。所以量子化就是把经典力学中的正则变量提升为算符，Poisson 括号替换为对易关系。进一步地，哈氏量可以变成哈氏量算符 $\hat H=\frac{\hat p^2}{2m}+V(\hat x)$。故具体的称呼是\textbf{正则量子化}(canonical quantization)。

下面我们来考察算符可能的数学表示。人们现已广泛清楚，矩阵乘法不对易，因此矩阵（尤其是方阵）是合适的数学候选。如此，量子态就是列矢，Dirac 把它写作 $\ket{}$。一般会在里面放一些符号，仅表标签含义，比如 $\ket{\psi}$。全体 $\ket{\psi}$ 构成线性空间。再补充一些条件后，这个空间成为了俗称的\textbf{Hilbert 空间}，记作 $\Hilbert$，作为量子态的数学载体。算符在这个意义下就将是线性变换，故也称\textbf{线性算符}。
但在当时，矩阵并非必学知识。Heisenberg 从 Poisson 括号绕了一圈才回到了矩阵乘法，相当于重新发明了矩阵。可以说，今日之大学得以普及线性代数，有 Heisenberg 的功劳。
不过这里会比我们学的线性代数复杂：因为可以证明，任意有限维度的矩阵都无法凑出对易关系。因此，算符必须是无限维空间上的矩阵。
相较于 Heisenberg，Schr\"odinger 更关注于量子态的具体表示，方法会更简单些。
他考虑的算符是直接的偏微分算符，比如 $\grad=\pdv{\bm x}$ 和 $\pdv{t}$。因此量子态可以表示为某种实变但复值的函数，称为\textbf{波函数}(wave function)。
后面会证明两种观点等价，或者说态矢、波函数有对应关系。
这也解释了为什么 Hilbert 线性空间是无穷维的，因为波函数需要遍历不可数的 $\bm x,t$，即函数空间是无穷维的；相应地，微分算符也无法展开为有限级数的形式。

由于现在提升为算符，可能的测量值几乎只能解释为算符的某个本征值：如果 $\hat A$ 具有一系列本征值 $\{a_n\}$，测量 $A$ 的结果只能是 $\{a_n\}$ 中的一个。一种 $a_n$ 称为一种\textbf{谱}(spectrum)。
回忆一下，本征的定义无非是 $\hat A \ket{a_n}=a_n \ket{a_n}$，这里 $\ket{a_n}$ 是 $\hat A$ 对应谱 $a_n$ 的本征矢，所以用了标签 $a_n$，仅此而已。
由于 $a_n$ 是仪器的测量结果，我们自然希望 $a_n\in\R$，即使 $\Hilbert$ 是涉及复数的。
若 $\{a_n\}$ 是有限或可数的，一般来说 $\hat A$ 就可称具有\textbf{离散谱}或\textbf{分立谱}，否则称\textbf{连续谱}\footnote{这个说法只是简化，不完全正确。}。
Born 借用杨⽒双缝实验的思想提出：给定离散谱可观测量算符，应当使任意态可分解为形如 $\ket\psi=\sum_n c_n \ket{a_n}$，称 $\{a_n\}$ \textbf{完备}；测到结果 $a_n$ 的概率由态决定，为 $|c_n|^2/\sum_n |c_n|^2 \in [0,1]$。
通常也约定 $\sum_n |c_n|^2=1$，称态矢的\textbf{归一化条件}。
这是量子力学必涉及复数的另一处体现：使 $\psi,c_n$ 涉及复数可以来源于波动理论（电磁学、光学）的复数方法。
相差倍数的态矢认为一致，形象的说法是称量子态实质是 Hilbert 空间中的一系列态矢，而不只是单独某个态矢。这些态矢的终点连成一条射线。
并且，如果做整体相位变换 $\ket\psi \to \e^{\i\alpha}\ket\psi$，概率密度分布是不变的，因此观测上无法区分，故认同 $\e^{\i\alpha}\ket\psi\sim\ket\psi$。

已知 $\psi,\{a_n\}$ 欲求出展开系数 $\{c_n\}$。按朴素思想，我们是将系数解释为 $\ket{\psi}$ 在 $\ket{a_n}$ 的投影。
由于我们现在考虑的是复线性空间，所以内积的定义方式会区别于实线性代数，满足：
\begin{itemize}
    \item $\ip{A}{B}=\ip{B}{A}^*$（复共轭）。
    \item $\ip{A}{A}\geq 0$，且 $\ip{A}{A}=0\iff \ket{A}=0$。
    \item $\ip{A}{B+C}=\ip{A}{B}+\ip{A}{C}$。    \item $\ip{A}{\lambda b}=\lambda \ip{A}{B}$。
\end{itemize}
后两个条件表明对第二槽线性，但结合第一条可知对第一槽\textbf{反线性}：$\ip{\lambda A}{B}=\lambda^* \ip{A}{B}$。
这里我们仍是将括号 $\ip{A}{B}$ 视作两个列矢 $\ket{A},\ket{B}$ 的内积。但注意到行矢 $\times$ 列矢也可视作内积。所以，其实可以把单独的 $\bra{A}$ 解释为 $\ket{A}$ 的转置，而成为行矢。注意内积反线性，故不仅要转置，而要\textbf{共轭转置}，用符号 $\dagger$ 表示：
\eq{
    \bra{\psi} := {\ket{\psi}}^\dagger = \sum_n c_n^* \bra{a_n}.
}

$P_n := \op{a_n}$ 称为\textbf{投影算符}，这里 $\op{}$ 表示列矢 $\times$ 行矢，结果是矩阵。
如果希望
\eq{
    \tcbhighmath{\sum_n \op{a_n} = 1} \im \hat A = \sum_n \hat A \op{a_n} = \sum_n a_n \op{a_n}.
}
则任意态矢展开为
\eq{
    \ket\psi = \sum_n \op{a_n} \ket\psi = \sum_n \ket{a_n} \ip{a_n}{\psi}.
}
任二态矢的内积可写为
\eq{
    \ip{\phi}{\psi} = \sum_n \ip{\phi}{a_n} \ip{a_n}{\psi}.
}
从而
\eq{
    \ip{a_n}{\psi} = \sum_m \ip{a_n}{a_m} \ip{a_m}{\psi} \iff \ip{a_n}{a_m} = \delta_{nm}.
}
这说明 $\{a_n\}$ 是正交归一基。这也说明系数的确为 $\ip{a_n}{\psi} = \sum_m c_m \delta_{nm} = c_n$。可见基底的完备性可完全体现在 $\sum_n \op{a_n} = 1$。测量概率为 $P(a_n)=\ev{P_n}{\psi}/\ip{\psi}$。
上述性质导致 $\hat A$ 是\textbf{自伴的}：
\eq{
    \hat A = \sum_n a_n \op{a_n} = \sum_n a_n^* \op{a_n} = \hat A^\dagger.
}
所以也是\textbf{Hermite 的}：
\eq{
    \mel{\phi}{\hat A}{\psi} = \ip{\hat A\phi}{\psi},\quad \text{其中}\, \ket{\hat A\phi} := \hat A\ket{\phi},\enspace \bra{\hat A\phi} = \ket{\hat A\phi}^\dagger = \bra{\phi} \hat A^\dagger.
}
反之给定自伴性，数学上可证，存在 $\{\ket{a_n}\}$ 满足 $\hat A \ket{a_n}=a_n \ket{a_n}$、$a_n\in\R$、完备且正交归一，且能对算符进行谱分解 $\hat A = \sum_n a_n \op{a_n}$，这称为\textbf{谱分解定理}。
所以，我们可将若干性质简洁地统一说法：\textit{规定可观测量 $\hat A$ 自伴}。
注意 $\ip{\psi} = \sum_n \abs{\ip{a_n}{\psi}}^2$，可见归一化条件也写作 $\ip{\psi}=1$。
根据概率论，算符 $\hat A$ 的平均值或期望值为
\eq{
    \ev{A} := \frac{1}{\ip{\psi}}\sum_{n} a_n \abs{\ip{a_n}{\psi}}^2 = \frac{\ev{\hat A}{\psi}}{\ip{\psi}}.
}


下面推广到连续谱，位置算符 $\hat{\bm x}$ 就是典型例子。我们沿用自伴性的相关性质。将完备关系\textit{插入}在 $\hat A$ 中并利用本征性就完成了谱分解：
\eq{
    \hat{A}\ket{a}=a\ket{a},\quad \tcbhighmath{1 = \int\d a \op{a}} \im \hat A = \int\d{a} \hat A\op{a} = \int\d{a} a \op{a}.
}
其中沿用离散谱命题中不含求和的版本，不得不涉及求和时则尝试替换为积分。被积函数分布在 $a$ 所属的实数空间上，记测度微元为 $\d a$。当然数学上，谱分解定理保证了从自伴性导出积分形式。
从而
\begin{align}
    \ket{\psi} &= \int\d a \ket{a}\ip{a}{\psi},\quad \bra{\psi} = \int\d a \ip{\psi}{a}\bra{a},\\
    \ip{a}{\psi} &= \int\d a' \ip{a'}{\psi} \ip{a}{a'} \iff \ip{a}{a'} = \delta(a-a'),\\
    \ip{\phi}{\psi} &= \int \d{a} \ip{\phi}{a} \ip{a}{\psi},\\
    \ev{A} := \frac{\ev{\hat A}{\psi}}{\ip{\psi}} &= \frac{1}{\ip{\psi}}\int \d{a} \mel{\psi}{\hat A}{a} \ip{a}{\psi} = \frac{1}{\ip{\psi}}\int \d{a} \ip{\psi}{a} \mel{a}{\hat A}{\psi}\\
    &= \frac{1}{\ip{\psi}}\int \d{a} a \abs{\ip{a}{\psi}}^2.
\end{align}
其中 $\delta(x)$ 就是我们熟悉的 Dirac 函数。
于是 $\abs{\ip{a}{\psi}}^2/{\ip{\psi}}$ 现在理解为测量出 $a$ 的概率密度。

取单粒子系统，位置本征矢为 $\{\ket{\bm x}\}$。这里均考虑欧氏空间 Descartes 坐标系，所以体积元是普通的 $\d[3]x$。态矢展开为
\eq{
    \ket{\psi} = \int\d[3]{x} \ket{\bm x}\ip{\bm x}{\psi}.
}
考虑归一化态矢，有
\eq{
    1 = \int\d[3]{x} \abs{\ip{\bm x}{\psi}}^2,\quad \ev{\bm x} = \int\d[3]{x} \bm x \abs{\ip{\bm x}{\psi}}^2.
}
说明 $\abs{\ip{\bm x}{\psi}}^2$ 可以理解为（某时刻）测量粒子发现在 $\bm x$ 的概率密度。
可见 Schr\"odinger 表述的等价性就体现在
\eq{
    \tcbhighmath{\psi(\bm x) := \ip{\bm x}{\psi},}\quad \psi^*(\bm x) = \ip{\psi}{\bm x}.
}
即波函数是 $\ket{\psi}$ 在 $\ket{\bm x}$ 上的分量。$\{\ket{\bm x}\}$ 也称为\textbf{坐标表象}或\textbf{位置表象}。
从而波函数的内积\footnote{这不是函数卷积。如果硬要写成卷积核形式，则是 $\ip{\phi}{\psi}=
\int\d x \d y \phi^*(x)\delta(x-y)\psi(y)$
其中恒等算符在坐标表象下的核是 $\delta(x-y)$。}和算符平均值为
\eq{
    \ip{\phi}{\psi} = \int\d[3]{x} \phi^*(\bm x) \psi(\bm x),\quad \ev{A} = \int\d[3]{x} \psi^*(\bm x) (\hat A \psi)(\bm x).
}
注意 $(\hat{\bm x} \psi)(\bm x) = \mel{\bm x}{\hat{\bm x}}{\psi} = \bm x\ip{\bm x}{\psi} = \bm x \psi(\bm x)$，这意味着在坐标表象下，位置算符 $\hat{\bm x}$ 表为单纯的实数乘法 $\bm x$，我们记作
\eq{
    \hat{\bm x} \to \bm x.
}
根据对易关系，由 Leibniz 乘法法则得 $\hat{\bm p} \to -\i\hbar\grad$。有时直接将箭头简记为等号。于是彻底还原了 Schr\"odinger 的微分算符理论。
当然，也可以采取\textbf{动量表象} $\{\ket{\bm p}\}$，\textbf{动量空间波函数}为 $\psi(\bm p) := \ip{\bm p}{\psi}$，从而 $\hat{\bm p}\to\bm p,\hat{\bm x}\to\i\hbar\pdv*{\bm p}$。

另一方面，$\hat{\bm p}$ 还可以解释对 $\bm x$ 平移的结果，于是自动得到自伴性和对易关系。考虑态矢的平移算符 $U(\bm a)$，它使得
\eq{
    U(\bm a)\ket{\bm x} = \ket{\bm x+\bm a} \im U(\bm a)U(\bm b)=U(\bm a+\bm b),\quad U(\bm 0)=1.
}
我们要求空间平移保持概率：$\abs{\ip{\phi'}{\psi'}}^2=\abs{\ip{\phi}{\psi}}^2$。从而算符是\textbf{幺正的}
\eq{
    U^\dagger U = UU^\dagger = 1,
}
因为根据 Wigner 定理，保持跃迁概率的变换只能由幺正或反幺正算符表示。而空间平移是连续变换，并且 $U(\bm 0)=1$，所以取幺正。或者直接推导出 $U(\bm a)^\dagger=U(-\bm a)$ 而看出。
进而 Stone 定理指出存在自伴算符 $\hat{\bm p}$ 满足
\eq{
    U(\bm a)=\exp\left(-\frac{\i}{\hbar}\bm a\vdot \hat{\bm p}\right).
}
这里算符（矩阵）的指数可理解为 Taylor 级数，其中乘法是算符按序作用（矩阵乘法）的次方。
小平移时（也即展开到一阶，略去$O(a^2)$）：
\[
U(\delta \bm a)
\simeq
1-\frac{\i}{\hbar}\delta\bm a\vdot \hat{\bm p}.
\]
故把 $\hat{\bm p}$ 称为空间平移的\textbf{无穷小生成元}(infinitesimal generator)，“生成元”意思是有限平移 $U(\bm a)$ 由 $\hat{\bm p}$ 指数化生成。当然，观察上式也可显式地写出 $\hat{\bm p}=\i\hbar\grad_{\bm a}U(\bm a)|_{\bm a=\bm 0}$。
由 $U(\bm a)\ket{\bm x} = \ket{\bm x+\bm a}$ 易得
\eq{
    U(\bm a)^\dagger \hat{\bm x} U(\bm a)
=
\hat{\bm x}+\bm a.
}
代入无穷小平移就得 $\hat{x}_i+\frac{\i}{\hbar} \sum_j a_j[\hat p_j,\hat x_i]=\hat{x}_i+a_i$，则我们由对称性推导出正则对易关系
\eq{
    [\hat x_i,\hat p_j]=\i\hbar \delta_{ij}.
}
取坐标表象，$\mel{\bm x}{U(\bm a)}{\psi}=\psi(\bm x-\bm a)$，
小平移展开：
\[
\psi(\bm x-\bm a)
\simeq
\psi(\bm x)-\bm a\vdot \grad\psi(\bm x).
\]
另一方面 $U(\bm a)\psi(\bm x)
\simeq
\left(1-\frac{\i}{\hbar}\bm a\vdot \hat{\bm p}\right)\psi(\bm x)$，
比较两边得 $\hat{\bm p}\psi(\bm x)=-\i\hbar\grad\psi(\bm x)$。

一旦我们尝试对 $\ket\psi$ 测量 $\hat A$ 得到某个确定结果 $a$，有趣的事情就会发生：\textit{理想测量后}，量子态就会投影到对应本征子空间，即
\eq{
    \ket\psi \to \frac{\op{a}\ket\psi}{\sqrt{\ev{\op{a}}{\psi}}} = \frac{\ip{a}{\psi}}{\abs{\ip{a}{\psi}}} \ket a \sim \ket a.
}
在相差一个整体相位的意义下，它等同于 $\ket a$。即测量后系统状态变成了对应的本征态，这称为\textbf{坍缩}(collapse)。可见测量不只是“读取”状态，它通常会改变状态，但也不能简单认为这是测量行为与态发生“相互作用”，因为坍缩的具体原因及过程目前尚无定论，涉及一个庞大的话题，称为\textbf{诠释}。无论具体诠释如何，其余的量子知识是完整且受到检验的。

数学上，Hilbert 空间的严格定义是配有复内积的完备的复线性空间。物理上采用的大多 $\ket{\psi}$ 也仅在这一空间内。但对它采取连续谱展开时，问题会变得微妙。
归一化条件其实说明了波函数至少是\textbf{平方可积函数}，所以单粒子 Hilbert 空间对应了 $\R^3$ 上全体的平方可积函数构成的集合 $L^2(\R^3)$。
坐标本征态 $\ket{\bm x_0}$ 的波函数为 Dirac 分布 $\delta(\bm x-\bm x_0)$，虽然 $\delta(\bm x)$ 积分为 1，但平方的积分是发散的：$\ip{\bm x_0}=\delta(\bm 0)$。所以 $\ket{\bm x_0}$ 其实不在 Hilbert 空间中。
关键原因是，$\delta(\bm x)$ 并不是普通的函数，而称为\textbf{分布}(distribution)。这种连续谱的特征矢称为\textbf{广义特征矢}(generalized eigenvector)。它生活在 Hilbert 空间的“一层薄薄的表面”上。这部分“表皮”加上 Hilbert 空间称为\textbf{装备}(rigged) Hilbert 空间。

另一个例子是动量本征态 $\ket{\bm p}$。其波函数记作 $\psi_{\bm p}(\bm x):=\ip{\bm x}{\bm p}$。由 $\hat{\bm p}\ket{\bm p}=\bm p\ket{\bm p}$，左乘坐标表象得到 $-\i\hbar\grad \psi_{\bm p}(\bm x)=\bm p \psi_{\bm p}(\bm x)$，方程的通解显然为简单平面波\footnote{一般的平面波指同相位点之集 $\bm x$ 满足 $\bm k\vdot\bm x$ 为常数，则波前为平面，通常直接把 $\e^{\i \bm k\vdot\bm x}$ 简称平面波。} $\psi_{\bm p}(\bm x) = C \e^{\i \bm p\vdot\bm x/\hbar}$。
剩下只是确定常系数。直接利用归一化条件会发现 $\int\d[3]{x} 1=\infty$，因此 $\ket{\bm p}$ 同样不在 Hilbert 空间。
但可利用
\[
    \delta(\bm p-\bm p') = \ip{\bm p}{\bm p'} = \int\d[3]{x} \ip{\bm p}{\bm x} \ip{\bm x}{\bm p'} = |C|^2 \int\d[3]{x} \e^{\i (\bm p'-\bm p)\vdot\bm x/\hbar}
\]
确定。
现在复习一下高数知识来判断平面波和 Dirac 函数的关系。
将任意函数视为周期无穷大的函数，先设有限周期 $L$，在 $[-L/2,L/2]$ 上 Fourier 级数展开为
\[f(x)=\sum_{N=-\infty}^\infty \frac{F(k_N)}{L} \e^{\i k_N x},\quad F(k_N)=\int_{-L/2}^{L/2}\d{x}\e^{-\i k_N x}f(x),\]
其中 $k_N={2\pi N}/{L}$ 称为\textbf{频谱}，与之相应的平面波 $\e^{\i k_N x}$ 称为该频谱的\textbf{模式}(mode)。$F(k)$（或记作 $\mathscr F(f)(k)$）称为 $f(x)$ 的\textbf{Fourier 变换}。随后令 $L\to\infty$，则 $\Delta k=2\pi/L\to 0$，级数化为积分，即 $f(x)=\int \frac{\d k}{2\pi} \e^{\i k x}F(k),F(k)=\int\d{x}\e^{-\i k x}f(x)$。
同理，取 $V=L^n$ 并连续化，可得
\eq{
    \tcbhighmath{
        f(x)=\int \frac{\d[n]k}{(2\pi)^n} \e^{\i k_\mu x^\mu}F(k),\quad F(k)=\int\d[n]{x}\e^{-\i k_\mu x^\mu}f(x).
    }
}
其中 $\mu$ 指标采用了求和约定\footnote{通常默认采用 Einstein 求和约定：上下重复指标只出现在需要求和时，所以不妨省略 $\sum_{\mu}$。}。于是我们很容易验证
\eq{
    1=\e^{0}=\int \frac{\d[n]k}{(2\pi)^n} \e^{\pm\i k_\mu x^\mu}(2\pi)^n\delta(k)\iff (2\pi)^n\delta(k) = \int\d[n]{x} \e^{\pm\i k_\mu x^\mu},
}
其中 $\delta(k)=\delta(k_1)\cdots\delta(k_n)$ 是 $n$ 维 Dirac 分布。因此常函数的 Fourier 变换就是动量空间上的 Dirac 函数。
代入 $\bm p = \hbar\bm k$ 有 $(2\pi\hbar)^3\delta(\bm p) = \int\d[3]{x} \e^{\pm\i \bm p\vdot\bm x/\hbar}$。
固定模长 $|C|$ 带来相差相因子 $\e^{\i\alpha(\bm p)}$（甚至可以考虑随动量可变的相位）的自由度。约定 $C\in[0,\infty)$，故
\eq{
    \psi_{\bm p}(\bm x) = \frac{1}{(2\pi\hbar)^{3/2}} \e^{\i \bm p\vdot\bm x/\hbar}.
}
显然动量完备关系为
\eq{
    \int\d[3]{p} \op{\bm p} = 1.
}
量子态展开为
\eq{
    \psi(\bm x) = \int\frac{\d[3]p}{(2\pi\hbar)^{3/2}} \psi(\bm p)  \e^{\i \bm p\vdot\bm x/\hbar},\quad \psi(\bm p) = \int\frac{\d[3]x}{(2\pi\hbar)^{3/2}} \psi(\bm x)\e^{-\i \bm p\vdot\bm x/\hbar}.
}
因此，我们也称任意函数都可把平面波作为展开基底。
这里注意 $\psi(\bm p)=\ip{\bm p}{\psi}$ 与 Fourier 变换结果相差常数因子。用 Fourier 变换的语言来写则是
\[
    \psi(\bm x) = \int\frac{\d[3]p}{(2\pi\hbar)^{3}} \tilde\psi(\bm p)  \e^{\i \bm p\vdot\bm x/\hbar},\quad \tilde\psi(\bm p) = \int \d[3]{x} \psi(\bm x)\e^{-\i \bm p\vdot\bm x/\hbar}.
\]
再次注意：严格说平面波本身不是可归一化态，而是广义本征态；真正的物理态是一系列不同频率的平面波的叠加，称为\textbf{波包}。

下面我们考虑孤立系统（在不测量时）关于时间 $t$ 的演化。考虑\textbf{Schr\"odinger 绘景}：态矢\textbf{显含时间}，写作 $\ket{\Psi(t)}$，而可观测量不具有由动力学演化产生的时间依赖，即算符不因绘景演化而含时，但仍允许显式含时。实验指出，态矢演化由含时幺正算符 $U$ 给出
\eq{
    \ket{\Psi(t)} = U(t,t_0)\ket{\Psi(t_0)}.
}
求导得\textbf{Schr\"odinger 方程}
\eq{
    i\hbar\dv{t}\ket{\Psi(t)}=\hat H(t)\ket{\Psi(t)},\quad \hat H(t) := \i\hbar \pdv{t}U(t,t_0) U^\dagger(t,t_0).
}
显然 $U$ 幺正使 $\hat H$ 自伴。$\hat H$ 称\textbf{哈氏算符}（能量算符），因为它是时间演化的无穷小生成元：
\eq{
    U(t+\delta t,t) \simeq 1-\frac{\i}{\hbar}\hat H(t)\delta t.
}
方程写成坐标表象就是 $\i\hbar\pdv{t}\Psi(\bm x,t)=\hat H\Psi(\bm x,t)$。
量子化给出了从\textit{经典力学}过渡到量子力学的方案：$H = \frac{{\bm p}^2}{2m} + V \to \hat H = \frac{\hat{\bm p}^2}{2m} + V(\hat{\bm x},t)$，
代入坐标表象得到所谓的含时 Schr\"odinger 方程
\eq{
    \tcbhighmath{\i\hbar\pdv{t}\Psi(\bm x,t)=\left(-\frac{\hbar^2}{2m}\nabla^2+V(\bm x,t)\right)\Psi(\bm x,t).}
}
最初 Schr\"odinger 通过波动力学的一些类比方法得到。
如果系统具有时间平移对称性，则 $\hat H$ 不含时，于是 $U(t,t_0)=\e^{-\frac{\i}{\hbar}\hat H(t-t_0)}$。这一结论也称 Stone 定理。接下来几乎只考虑不含时 $\hat H$。 

考虑能量本征方程
\eq{
    \hat H\ket{E}=E\ket{E}.
}
$E$ 是常数能量，无关 $\bm x,t$。
可将初态 $\ket{\Psi(0)}$ （$t_0=0$）分解到能量本征态上，或者说插入能量完备关系，其实就是 $\e^{-\frac{\i}{\hbar}\hat H t}$ 的谱分解，从而满足 Schr\"odinger 演化的任意含时波矢为
\[
    \ket{\Psi(t)} = \e^{-\frac{\i}{\hbar}\hat H t} \ket{\Psi(0)} = \sum_n \ip{E_n}{\Psi(0)} \e^{-\frac{\i}{\hbar}E_n t} \ket{E_n} \;\text{或}\;  \int\d{E} \ip{E}{\Psi(0)} \e^{-\frac{\i}{\hbar}E t} \ket{E}.
\]
普通教材以偏微分方程求解为主线，用所谓的\textbf{分离变量法}来求特解。具体思想就是把含时波函数写成乘积 $\Psi_\text{特}(\bm x,t)=f(t)\psi(\bm x)$，代入含时方程，从而将偏微分化为常微分，得知 $f(t)$ 的解为指数型，$\psi(\bm x)$ 正是能量本征态。在我们的表述里，可以显然地发现这一点：
\[
    \ket{\Psi_\text{特}(t)} = \e^{-\frac{\i}{\hbar}E t} \ket{E} \iff \Psi_\text{特}(\bm x,t) = \e^{-\frac{\i}{\hbar}E t} \psi(\bm x),\quad \psi(\bm x):=\ip{\bm x}{E}.
\]
相对而言 $\psi(\bm x)$ 就称为\textbf{定态}(stationary state)波函数。因此能量本征方程（的坐标表象）也称为\textbf{定态 Schr\"odinger 方程}。
通常教材说从 Schr\"odinger 方程观察出\textbf{线性叠加原理}：若 $\{\Psi_i(\bm x,t)\}$ 是解，则 $\sum_i c_i\Psi_i(\bm x,t)$ 也是解。
这也意味着 $\Psi(\bm x,t)$ 的重标度 $c\Psi(\bm x,t)$ 仍是解，故总可对（平方可积）波函数归一化。
按照我们的态矢记号，这其实就是线性空间上线性算符的结果。

考虑某个单一能量本征态，其形如 $\e^{-\frac{\i}{\hbar}E t} \psi(\bm x)$，即时间演化吸收进指数中，故只产生整体相位转动，换言之可观测的概率密度必然不随时间变化：
\[
    |\e^{-\frac{\i}{\hbar}E t} \psi(\bm x)|^2 = |\psi(\bm x)|^2,
\]
当然，一般叠加态 $\sum_n c_n \e^{-\frac{\i}{\hbar}E_n t} \psi_n(\bm x)$ 的概率密度通常会变。

考虑动量本征态 $\ket{\bm p}$。考虑\textbf{自由情形}：势能 $V$ 为常数 $V_0$（经常简单起见直接取 $V_0=0$），则（经典力学）哈氏量也只关于 $\hat{\bm p}^2$，因此动量本征态也一定是能量本征态：
\eq{
    -\i\hbar\grad \psi_{\bm p}(\bm x) =\bm p \psi_{\bm p}(\bm x) \im \hat H\psi_{\bm p}(\bm x)=E_{\bm p}\psi_{\bm p}(\bm x),\quad E_{\bm p} = \bm p^2/2m + V_0.
}
当然，能量本征态仍然不一定是动量本征态。
动量本征态是平面波，在自由条件下它也是定态方程的解，这说明自由 Schrödinger 方程的特解是这样的平面波：
\[
    \e^{\frac{\i}{\hbar}\bm p\vdot\bm x}\e^{-\frac{\i}{\hbar}E_{\bm p} t} = \e^{\frac{\i}{\hbar}(\bm p\vdot\bm x - E_{\bm p} t)}.
\]
波动学告诉我们角频率 $\omega$、波矢 $\bm k$ 满足 $\e^{\i(\bm k\vdot\bm x - \omega t)}$，这说明
\eq{
    \tcbhighmath{
    E_{\bm p} = h\nu = \hbar\omega,\quad \bm p = \hbar\bm k.
    }
}
从而波动性质满足着类似于经典力学的力学关系。上式正是\textbf{de Broglie 关系}。
如此，也就将 Planck 黑体辐射、Einstein 光电效应都包括在内。
由于平面波是自由线性方程的解，则平面波的线性叠加也是解，因此通解显然为平面波的 Fourier 叠加。更优雅的说法是对 $\e^{-\frac{\i}{\hbar}\hat H t}$ 谱分解：
\eq{
    \Psi(\bm x,t) = \int\d[3]p \ip{\bm x}{\bm p} \ip{\bm p}{\Psi(0)} \e^{-\frac{\i}{\hbar}E_{\bm p} t} = \int\frac{\d[3]p}{(2\pi\hbar)^{3}} \tilde\Psi(\bm p,0)  \e^{\frac{\i}{\hbar}(\bm p\vdot\bm x - E_{\bm p} t)},
}
每种模式具有相应动量 $\bm p$。
当然，还有一种做法是对良好的函数直接进行空间 Fourier 变换 $\tilde\Psi(\bm p,t)$，则展开为
\[\Psi(\bm x,t) = \int\frac{\d[3]{p}}{(2\pi\hbar)^3}\tilde\Psi(\bm p,t) \e^{\i \bm p\cdot\bm x/\hbar},\]
随后代入自由方程就可得 $\tilde\Psi(\bm p,t)$ 的一阶时间常微分方程，解得 $\tilde\Psi(\bm p,t) = \tilde\Psi(\bm p,0)\e^{-\i E_{\bm p} t/\hbar}$。
总之可见，自由哈氏量在动量表象下是对角的，所以每个动量模式只获得一个相位因子 $\e^{-\frac{\i}{\hbar}E_{\bm p} t}$。

哈氏量无非三种情形：
\begin{itemize}
    \item 离散谱：束缚态，例如无限深势阱、谐振子、氢原子的束缚能级；
    \item 连续谱：自由粒子、散射态、常势能粒子；
    \item 混合谱：比如氢原子有离散束缚态，也有连续电离态。
\end{itemize}

%% 绘景引入 - 参考 Sean Carrol

考虑态矢不含时，则算符必然含时，称\textbf{Heisenberg 绘景}。用下标 $S,H$ 分别表示两种绘景。
$\hat A_S$ 的平均值为 $\ev{A_S}(t)=\mel{\Psi(t)}{\hat A_S}{\Psi(t)}$，其中 $\hat A_S$ 本身不含时。同理，$\hat A_H$ 的平均值为 $\ev{A_H}(t)=\mel{\Psi_H}{\hat A_H(t)}{\Psi_H}$，其中 $\ket{\Psi_H}$ 不含时间。
要求绘景不改变任何可观测结果，即 $\ev{A_S}(t)=\ev{A_H}(t)$。
注意 $\ket{\Psi(t)}=U(t,t_0)\ket{\Psi(t_0)}$，Hermite 共轭为 $\bra{\Psi(t)}=\bra{\Psi(t_0)}U^\dagger(t,t_0)$，则不妨定义
\eq{
    \ket{\Psi_H}:=\ket{\Psi(t_0)},\quad
    \hat A_H(t):=U^\dagger(t,t_0)\hat A_S U(t,t_0),
}
轻松使得
\[
    \ev{A_S}(t)
    =
    \mel{\Psi(t_0)}{U^\dagger(t,t_0)\hat A_S U(t,t_0)}{\Psi(t_0)}
    =
    \mel{\Psi_H}{\hat A_H(t)}{\Psi_H}
    =\ev{A_H}(t).
\]
如此，Heisenberg 绘景只是把同一演化从态矢转移到算符上。取 Schr\"odinger 绘景的哈氏算符 $\hat H$。由 $U(t,t_0)=\e^{-\frac{\i}{\hbar}\hat H(t-t_0)}$
知
\[
    \dv{U}{t}=-\frac{\i}{\hbar}\hat H U,\quad
    \dv{U^\dagger}{t}=\frac{\i}{\hbar}U^\dagger\hat H,
\]
其中第二式也可由 $U^\dagger U=1$ 对时间求导得到。于是
\begin{align*}
    \dv{\hat A_H}{t}
    &=
    \dv{U^\dagger}{t}\hat A_S U
    +U^\dagger\hat A_S\dv{U}{t}=
    \frac{\i}{\hbar}U^\dagger\hat H\hat A_S U
    -\frac{\i}{\hbar}U^\dagger\hat A_S\hat H U\\
    &=
    \frac{\i}{\hbar}
    \left(
        U^\dagger\hat H U U^\dagger\hat A_S U
        -
        U^\dagger\hat A_S U U^\dagger\hat H U
    \right)=
    \frac{\i}{\hbar}[\hat H_H(t),\hat A_H(t)].
\end{align*}
如果 $\hat H$ 不含时，则 $\hat H_H=U^\dagger \hat H U=\hat H$，因为 $\hat H$ 与它自身的指数函数对易。因此两种绘景的哈氏算符是完全一样的，均记 $\hat H$。于是 Heisenberg 绘景下算符的运动方程为\textbf{Heisenberg 方程}
\eq{
    \dv{\hat A_H}{t}
    =
    \frac{\i}{\hbar}[\hat H,\hat A_H]
    =
    \frac{1}{\i\hbar}[\hat A_H,\hat H].
}
若 $\hat A_S(t)$ 本身含时，比如外场或人为调节的测量装置带来一个显含 $t$ 的算符，只需类似地定义 $\hat A_H(t)=U^\dagger(t,t_0)\hat A(t)U(t,t_0)$，随后乘法求导还多出一项：
\eq{
    \dv{\hat A_H}{t}
    =
    \frac{\i}{\hbar}[\hat H_H,\hat A_H]
    +\left(\pdv{\hat A_S}{t}\right)_H,\quad \left(\pdv{\hat A_S}{t}\right)_H
    :=
    U^\dagger\pdv{\hat A_S}{t}U.
}
经典力学中任意相空间函数 $A(q,p,t)$ 满足
\[
    \dv{A}{t}=\{A,H\}+\pdv{A}{t},
\]
其中 $\{A,H\}$ 是 Poisson 括号。量子理论中相应地有
\eq{
    \{A,H\}\quad \longrightarrow\quad \frac{1}{\i\hbar}[\hat A,\hat H].
}
这解释了为什么 Heisenberg 当初会从 Poisson 括号的结构走向矩阵乘法的非对易性。
比如，考虑非相对论粒子 $\hat H={\hat{\bm p}^2}/{2m}+V(\hat{\bm x})$。
在 Heisenberg 绘景中写作 $\hat{\bm x}_H(t),\hat{\bm p}_H(t)$，很容易得到\textbf{等时对易关系}
\eq{
    [\hat{\bm x}_H(t),\hat{\bm p}_H(t)] = \i\hbar,
}
即正则对易关系的形式不依赖于绘景。
下面为简洁省略下标 $H$。显然 $[\hat x_i,\hat{\bm p}^2]=[\hat x_i,\hat p_j]\hat p_j+\hat p_j[\hat x_i,\hat p_j]=2\i\hbar\hat p_j$。
并且 $\hat{\bm x}$ 与 $V(\hat{\bm x})$ 对易，所以
\[
    \dv{\hat{\bm x}}{t}
    =
    \frac{1}{\i\hbar}[\hat{\bm x},\hat H]
    =
    \frac{1}{\i\hbar}\frac{1}{2m}[\hat{\bm x},\hat{\bm p}^2]
    =
    \frac{\hat{\bm p}}{m}.
\]
再看动量。由于 $\hat{\bm p}$ 与 $\hat{\bm p}^2$ 对易，只需计算 $[\hat{\bm p},V(\hat{\bm x})]$。在坐标表象中，$\hat{\bm p}=-\i\hbar\grad$，作用在任意测试波函数 $\psi(x)$ 上：$[\hat{\bm p},V(\hat{\bm x})]\psi=-\i\hbar\grad(V(x)\psi(x))+\i\hbar V(x)\grad\psi(x)=-\i\hbar\grad V\psi(x)$。
故作为算符恒等式，$[\hat{\bm p},V(\hat{\bm x})]=-\i\hbar \grad V(\hat{\bm x})$。
于是
\[
    \dv{\hat{\bm p}}{t}
    =
    \frac{1}{\i\hbar}[\hat{\bm p},\hat H]
    =
    -\grad V(\hat{\bm x}).
\]
可见 Heisenberg 绘景保留了经典力学中“物理量随时间演化”的直观形式，只是普通变量被非对易算符取代，Poisson 括号被对易子取代。
还有一个常用推论。若某个算符 $\hat A$ 不含时，且与哈氏量对易 $[\hat A,\hat H]=0$，则
\eq{
    \dv{\hat A_H}{t}=0.
}
因此 $\hat A$ 对应守恒量。例如自由粒子 $V=0$ 时，$[\hat{\bm p},\hat H]=0$，动量守恒；若势能具有空间平移或旋转对称性，相应的动量或角动量也会守恒。这与经典力学中“对称性给出守恒量”的思想一致，后文场论中仍会反复使用。

最后来看看复合系统的态，称为\textbf{复合态}。如果有两个系统，态空间分别为 $\Hilbert_A$、$\Hilbert_B$，实验表明复合态属于张量积空间
\eq{
    \Hilbert_{AB}=\Hilbert_A\otimes \Hilbert_B.
}
此时，单独的一个系统的态称为\textbf{纯态}。
如果已知两者各自纯态 $\ket{\psi_A}$、$\ket{\psi_B}$，则复合态就是张量积形式 $\ket{\psi_{AB}}=\ket{\psi_A,\psi_B} \in \Hilbert_{AB}$，
这里做了简写 $\ket{\psi_A,\psi_B}=\ket{\psi_A}\ket{\psi_B}=\ket{\psi_A}\otimes\ket{\psi_B}$。
但复合态不一定都能写成张量积，这时称为\textbf{纠缠}(entanglement)态。比如
\[
\ket{\psi_{AB}}=\frac{1}{\sqrt{2}}(\ket{0}_A\ket{0}_B+\ket{1}_A\ket{1}_B)
\]
不能写成单独的纯态张量积形式。

考虑多粒子系统，我们把复合态矢投影到多粒子的坐标表象上：
\eq{
    \psi(\bm x_1,\cdots\bm x_N,t) := \ip{\bm x_1,\cdots\bm x_N}{\Psi(t)},\quad \ket{\bm x_1,\cdots\bm x_N} = \ket{\bm x_1}\cdots\ket{\bm x_N}.
}
所以波函数不再单纯是一个时空上的函数。
粒子数的增加导致系统的量子态空间维数呈指数级增长。
这时 Heisenberg 态矢描述显得比波函数简洁。
我们甚至可以说整个宇宙的量子态是一个庞大的态矢 $\ket{\psi}$。
态矢展开为
\eq{
    \tcbhighmath{\ket{\psi} = \int\d[3]{x_1}\cdots \d[3]{x_N} \ket{\bm x_1,\cdots,\bm x_N} \psi(\bm x_1,\cdots,\bm x_N).}
}
归一化条件是
\eq{
    1 = \int\d[3]{x_1}\cdots \d[3]{x_N} \abs{\psi(\bm x_1,\cdots,\bm x_N)}^2.
}
如果态矢是积态，即 $\ket{\psi}=\ket{\psi_1}\cdots\ket{\psi_N}$，则波函数也写作简单的乘法形式：
\eq{
    \psi(\bm x_1,\cdots,\bm x_N) = \psi_1(\bm x_1)\cdots\psi_N(\bm x_N).
}
纠缠态则无法写成积态。
上面写 $\ket{\bm x_1,\cdots,\bm x_N}$ 时，其实已经临时给粒子贴上了 $1,\cdots,N$ 的标签。对于电子和质子这样的不同粒子，标签有物理意义，因为质量、电荷等可观测量足以区分它们；但对于两个电子，所谓“第一个电子”和“第二个电子”只是人为编号。实验上能观测的是“有一个电子在某处，另一个电子在某处”，而不是哪一个编号的电子在某处。因此，全同粒子的量子态必须对这种人为编号的改变给出相同物理预言。

先看两个全同粒子。设单粒子态空间为 $\Hilbert$，暂时仍用带标签的张量积空间 $\Hilbert\otimes\Hilbert$ 描述。定义交换算符
\eq{
    \hat P_{12}\ket{\alpha,\beta}=\ket{\beta,\alpha},
}
其中 $\alpha,\beta$ 可以代表位置、动量、自旋等完整单粒子量子数。显然
\eq{
    \hat P_{12}^2=1,\quad \hat P_{12}^{-1}=\hat P_{12},\quad \hat P_{12}^\dagger=\hat P_{12}.
}
全同粒子的意思就是任意可观测量 $\hat A$ 不依赖粒子编号，即
\eq{
    [\hat A,\hat P_{12}]=0,
}
于是交换前后的态给出相同平均值：
\eq{
    \frac{\mel{\hat P_{12}\psi}{\hat A}{\hat P_{12}\psi}}{\ip{\hat P_{12}\psi}}
    =
    \frac{\mel{\psi}{\hat P_{12}^\dagger\hat A\hat P_{12}}{\psi}}{\ip{\psi}}
    =
    \frac{\ev{\hat A}{\psi}}{\ip{\psi}}.
}
若交换后仍描述同一个纯态射线，则只能相差一个整体相位：
\eq{
    \hat P_{12}\ket{\psi}=\e^{\i\theta}\ket{\psi}.
}
再作用一次交换算符，利用 $\hat P_{12}^2=1$，得到 $\ket{\psi}=\hat P_{12}^2\ket{\psi}=\e^{2\i\theta}\ket{\psi}$。
因此 $\e^{\i\theta}=\pm 1$。这就得到两种可能：
\eq{
    \hat P_{12}\ket{\psi}=+\ket{\psi},\quad
    \hat P_{12}\ket{\psi}=-\ket{\psi}.
}
前者称为交换\textbf{对称}态，对应\textbf{玻色子}(boson)；后者称为交换\textbf{反对称}态，对应\textbf{费米子}(fermion)。

在坐标表象中，这个结论写得更直观。
由于 $\bra{\bm x_1,\bm x_2}\hat P_{12}=\bra{\bm x_2,\bm x_1}$，
有 $\ip{\bm x_1,\bm x_2}{\hat P_{12}\psi}=\ip{\bm x_2,\bm x_1}{\psi}=\psi(\bm x_2,\bm x_1)$，
所以对称、反对称条件分别变成
\eq{
    \psi(\bm x_2,\bm x_1)=+\psi(\bm x_1,\bm x_2),\quad
    \psi(\bm x_2,\bm x_1)=-\psi(\bm x_1,\bm x_2).
}
严格地说，若粒子还带有自旋等内禀自由度，交换的不是单纯的位置变量，而是完整单粒子量子数。记 $\alpha=(\bm x,s,\cdots)$，则应写为
\eq{
    \psi(\alpha_2,\alpha_1)=\pm\psi(\alpha_1,\alpha_2).
}
也就是说，电子的费米反对称性是对“位置加自旋”等所有单粒子标签同时交换而言的。

对于 $N$ 个全同粒子，交换操作推广为置换群 $S_N$ 的作用。对任意置换 $\sigma\in S_N$，设 $\hat U_\sigma$ 是相应的粒子标签置换算符。三维空间中的全同粒子只有两类一维交换表示：
\eq{
    \hat U_\sigma\ket{\psi_+}=\ket{\psi_+},\quad
    \hat U_\sigma\ket{\psi_-}=\sgn(\sigma)\ket{\psi_-},
}
其中 $\sgn(\sigma)=+1$ 表示偶置换，$\sgn(\sigma)=-1$ 表示奇置换。坐标表象下相应地有
\begin{align}
    \psi_+(\alpha_{\sigma(1)},\cdots,\alpha_{\sigma(N)})
    &=
    \psi_+(\alpha_1,\cdots,\alpha_N),\\
    \psi_-(\alpha_{\sigma(1)},\cdots,\alpha_{\sigma(N)})
    &=
    \sgn(\sigma)\psi_-(\alpha_1,\cdots,\alpha_N).
\end{align}
所以玻色子的多粒子波函数在任意交换下不变，费米子的多粒子波函数在奇置换下变号。
这也说明，并非整个张量积空间 $\Hilbert^{\otimes N}$ 都是全同粒子的物理态空间，而只能取其中的对称或反对称部分。定义投影算符
\eq{
    \hat S_\pm
    :=
    \frac{1}{N!}\sum_{\sigma\in S_N}(\pm)^\sigma \hat U_\sigma,
}
其中 $(+)^\sigma=1$，而 $(-)^\sigma=\sgn(\sigma)$。由于 $\sgn(\sigma\tau)=\sgn(\sigma)\sgn(\tau)$，有
\[
    \hat S_\pm^2
    =
    \frac{1}{(N!)^2}\sum_{\sigma,\tau\in S_N}
    (\pm)^\sigma(\pm)^\tau \hat U_{\sigma\tau} =
    \frac{1}{(N!)^2}\sum_{\rho\in S_N}
    \sum_{\sigma\in S_N}(\pm)^\rho \hat U_\rho
    =
    \frac{1}{N!}\sum_{\rho\in S_N}(\pm)^\rho \hat U_\rho
    =
    \hat S_\pm.
\]
所以 $\hat S_\pm$ 的确是投影。全同玻色子、费米子的 $N$ 粒子态空间分别为
\eq{
    \Hilbert^{(N)}_+ = \hat S_+\Hilbert^{\otimes N},\quad
    \Hilbert^{(N)}_- = \hat S_-\Hilbert^{\otimes N}.
}

特别地，若两个单粒子态为 $\ket{\phi},\ket{\chi}$，则由可区分粒子的张量积态 $\ket{\phi,\chi}$ 出发，物理的全同粒子态应先投影：
\eq{
    \ket{\phi,\chi}_\pm
    =
    \frac{\ket{\phi}\ket{\chi}\pm\ket{\chi}\ket{\phi}}
    {\sqrt{2(1\pm\abs{\ip{\phi}{\chi}}^2)}}.
}
分母来自归一化。事实上，若 $\ip{\phi}=\ip{\chi}=1$，则
\begin{align*}
    \bigl(\bra{\phi}\bra{\chi}\pm\bra{\chi}\bra{\phi}\bigr)
    \bigl(\ket{\phi}\ket{\chi}\pm\ket{\chi}\ket{\phi}\bigr) =
    2\pm 2\abs{\ip{\phi}{\chi}}^2
    =
    2(1\pm\abs{\ip{\phi}{\chi}}^2).
\end{align*}
若 $\ket{\phi}=\ket{\chi}$，则得到\textbf{Pauli 不相容原理}
\eq{
    \ket{\phi,\phi}_-=0.
}
即两个全同费米子不能处于同一个完整单粒子态。若写成波函数语言，$N$ 个费米子的反对称态可表为 Slater 行列式
\eq{
    \psi_-(\alpha_1,\cdots,\alpha_N)
    =
    \frac{1}{\sqrt{N!}}
    \det\bigl(\phi_i(\alpha_j)\bigr),
}
一旦两行相同，行列式立刻为零；这正是 Pauli 原理的数学形式。玻色子则没有这个限制，多个玻色子可以处于同一单粒子态。

量子统计正是从这种交换对称性来的。设有 $g$ 个单粒子模式，记第 $r$ 个模式上的占有数为 $n_r$。全同粒子没有“第几个粒子占据第几个模式”的说法，只有“每个模式中有多少粒子”的说法。固定总粒子数 $N$ 时
\eq{
    \sum_{r=1}^{g} n_r=N.
}
对玻色子，$n_r=0,1,2,\cdots$，即同一模式可放任意多个粒子。于是态数等于非负整数解的个数：
\eq{
    W_B(g,N)
    =
    \#\{(n_1,\cdots,n_g)\mid n_r\geq 0,\ \sum_r n_r=N\}
    =
    \binom{N+g-1}{N}.
}
最后一个等号可用“隔板法”理解：把 $N$ 个粒子看作 $N$ 个星号，用 $g-1$ 个隔板分成 $g$ 组，总共有 $N+g-1$ 个位置，任选 $N$ 个位置放星号即可。
对费米子，Pauli 原理要求
\eq{
    n_r=0,1.
}
因此只需从 $g$ 个模式中选出 $N$ 个被占据的模式：
\eq{
    W_F(g,N)=\binom{g}{N}.
}
这两个计数方式分别称为 Bose-Einstein 统计和 Fermi-Dirac 统计的计数基础。

若进一步考虑无相互作用粒子的热平衡，设第 $r$ 个模式能量为 $\epsilon_r$，温度 $T$ 下 $\beta=1/(k_B T)$，化学势为 $\mu$。用巨正则系综时，一个模式占有数为 $n_r$ 的权重为
\eq{
    \e^{-\beta(\epsilon_r-\mu)n_r}.
}
由于不同模式独立，配分函数按模式分解。对玻色子，
\eq{
    Z_r^{(B)}
    =
    \sum_{n=0}^{\infty}\e^{-\beta(\epsilon_r-\mu)n}
    =
    \frac{1}{1-\e^{-\beta(\epsilon_r-\mu)}}.
}
对费米子，由于 $n=0,1$，
\eq{
    Z_r^{(F)}
    =
    \sum_{n=0}^{1}\e^{-\beta(\epsilon_r-\mu)n}
    =
    1+\e^{-\beta(\epsilon_r-\mu)}.
}
记 $q_r=\e^{-\beta(\epsilon_r-\mu)}$，平均占有数为
\eq{
    \bar n_r
    =
    \frac{1}{Z_r}\sum_n n q_r^n
    =
    q_r\pdv{}{q_r}\ln Z_r.
}
于是得到
\eq{
    \bar n_r^{(B)}
    =
    \frac{1}{\e^{\beta(\epsilon_r-\mu)}-1},\quad
    \bar n_r^{(F)}
    =
    \frac{1}{\e^{\beta(\epsilon_r-\mu)}+1}.
}
这就是常说的 Bose-Einstein 分布和 Fermi-Dirac 分布。可见两种统计并非热力学中的人为规定，而是多粒子量子态交换性质的直接后果。

\section{相互作用绘景}

存在相互作用时，在 Schr\"odinger 绘景中，将哈氏量分解为 $\hat H = \hat H_0 + \hat H_1$，其中 $\hat H_0$ 是自由哈氏量，$\hat H_1$ 是相对于 $\hat H_0$ 的相互作用部分。
下面均考虑 $\hat H_0,\hat H_1$ 不含时的情形。可建立\textbf{相互作用绘景}(interaction picture)，也称\textbf{Dirac 绘景}。
以下讨论以 $0$ 作为绘景变换的参考时刻，如果想将参考时刻改为 $t_0$，只需要作变量替换 $t\to t- t_0$。定义
\eq{
    \ket{\Psi_D(t)} := \e^{\frac{\i}{\hbar}\hat H_0 t}\ket{\Psi(t)},\quad
    \hat A_D(t) := \e^{\frac{\i}{\hbar}\hat H_0 t}\hat A\e^{-\frac{\i}{\hbar}\hat H_0 t}.
}
动机是使态矢和算符都含时，且演化方程各自只依赖于一个哈氏量。
这样一来，相互作用绘景中 $\hat H_0^D = \hat H_0$，但 $\hat H_D(t)\ne\hat H$，$\hat H_1^D(t) = \hat H^D(t) - \hat H_0^D$。
注意 Schr\"odinger 绘景与 Heisenberg 绘景的变换关系为
\[
    \e^{-\frac{\i}{\hbar}\hat H t}\ket{\Psi_H}=\ket{\Psi(t)},\quad
    \e^{-\frac{\i}{\hbar}\hat H t}\hat A_H(t)\e^{\frac{\i}{\hbar}\hat H t}=\hat A.
\]
以 Schr\"odinger 绘景为中介，可得相互作用绘景与 Heisenberg 绘景之间的关系
\eq{
    \ket{\Psi_D(t)}=V(t)\ket{\Psi_H},\quad
    \hat A_D(t)=V(t)\hat A_H(t)V^\dagger(t),\quad V(t):=\e^{\frac{\i}{\hbar}\hat H_0 t}\e^{-\frac{\i}{\hbar}\hat H t}.
}
其中注意幺正算符 $V$ 的共轭 $V^\dagger(t)=\e^{\frac{\i}{\hbar}\hat H t}\e^{-\frac{\i}{\hbar}\hat H_0 t}$。
幺正变换保持等时对易关系的形式：
\eq{
    [\hat A_D(t),\hat B_D(t)]
    =V(t)[\hat A_H(t),\hat B_H(t)]V^\dagger(t).
}
在 $t=0$ 时三种绘景一致；任意时刻均有
\eq{
    \mel{\Psi(t)}{\hat A_S}{\Psi(t)}
    =\mel{\Psi_D(t)}{\hat A_D(t)}{\Psi_D(t)}
    =\mel{\Psi_H}{\hat A_H(t)}{\Psi_H},
}
故三者描述相同的物理。若无相互作用，即 $\hat H_1=0$，则 $V(t)=1$，相互作用绘景退化为 Heisenberg 绘景。
由定义和 Schr\"odinger 方程，
\begin{align*}
    \i\hbar\dv{t}\ket{\Psi_D(t)}
    &=
    -\hat H_0\ket{\Psi_D(t)}
    +\e^{\frac{\i}{\hbar}\hat H_0 t}\hat H\ket{\Psi(t)}\\
    &=
    \e^{\frac{\i}{\hbar}\hat H_0 t}(\hat H-\hat H_0)\ket{\Psi(t)}
    =\hat H_1^D(t)\ket{\Psi_D(t)}.
\end{align*}
因此相互作用绘景的态矢演化方程为
\eq{
    \i\hbar\dv{t}\ket{\Psi_D(t)}
    =\hat H_1^D(t)\ket{\Psi_D(t)},\quad
    \hat H_1^D(t)=\e^{\frac{\i}{\hbar}\hat H_0 t}\hat H_1\e^{-\frac{\i}{\hbar}\hat H_0 t}.
}
另一方面，对可能显含时间的算符 $\hat A_S(t)$ 求导，得到
\begin{align*}
    \dv{\hat A_D(t)}{t}
    &=
    \frac{\i}{\hbar}\hat H_0\hat A_D(t)
    -\frac{\i}{\hbar}\hat A_D(t)\hat H_0
    +\e^{\frac{\i}{\hbar}\hat H_0 t}
    \pdv{\hat A_S(t)}{t}
    \e^{-\frac{\i}{\hbar}\hat H_0 t}\\
    &=
    \frac{\i}{\hbar}[\hat H_0,\hat A_D(t)]
    +\left(\pdv{\hat A_S(t)}{t}\right)_D.
\end{align*}
这就是相互作用绘景的算符演化方程；若 $\hat A_S$ 不显含时间，末项为零。可见，态矢演化遵循 $\hat H_1^D(t)$ 的 Schr\"odinger 方程，算符演化遵循 $\hat H_0$ 的Heisenberg 方程。
在 Heisenberg 绘景中，对未加相互作用的系统求出各个算符间的关系之后，加入相互作用有可能改变这些关系。不过在相互作用绘景中，加入后的算符关系，仍然与加入前在 Heisenberg 绘景中的关系相同，可以直接套用原来的公式，这就是相互作用绘景的好处。

综上，相互作用绘景下，$\hat H_1^D(t)$ 的影响由态矢承载，其演化等价为
\eq{
    \ket{\psi_D(t)} = U_D(t,t_0)\ket{\psi_D(t_0)},\quad U_D(t,t_0) = V(t)V^\dagger(t_0),\quad
    \i\hbar\pdv{t}U_D(t,t_0) = \hat H_1^D(t)U_D(t,t_0).
}
接下来，省略表示相互作用绘景标志，默认在相互作用绘景中讨论。
设 $t\geqslant t_0$，结合初始条件 $U(t_0,t_0) = 1$，将方程的解表达为
\eq{
    U(t,t_0) = 1 - \frac{\i}{\hbar}\int_{t_0}^t\d{t_1} \hat H_1(t_1)U(t_1,t_0) .
}
不断迭代就有
\eq{
    U(t,t_0) = \sum_{n=0}^\infty \left(-\frac{\i}{\hbar}\right)^n \int_{t_0}^t\d{t_1}\cdots\int_{t_0}^{t_{n-1}}\d{t_n} \hat H_1(t_1)\cdots\hat H_1(t_n),
}
其中积分上限时刻呈降序排列 $t\geqslant t_1\geqslant \cdots \geqslant t_n\geqslant\cdots\geqslant t_0$。
由于积分上限与积分变量相互依赖，这样的多重积分很难处理。为将每个积分的区间都扩展成 $[t_0, t]$，引入\textbf{时序乘积}或\textbf{编时乘积}的概念。无论 $t_1,\cdots,t_n$ 是否排序，这种乘积使结果一定按时间降序排列：
\eq{
    \Tord[A(t_1)\cdots A(t_n)] = A(t_{\sigma(1)})\cdots A(t_{\sigma(n)}),\quad t_{\sigma(1)}\geqslant \cdots \geqslant t_{\sigma(n)}.
}
即时间较晚的算符放在左边。比如对两个玻色型算符（$\hat A\hat B = \hat B\hat A$），
\eq{
    \Tord[\hat A(t_1)\hat B(t_2)]
    =
    \theta(t_1-t_2)\hat A(t_1)\hat B(t_2)
    +
    \theta(t_2-t_1)\hat B(t_2)\hat A(t_1),
}
其中阶跃函数为
\[
    \theta(t)=\begin{cases}
        1, & t>0,\\
        0, & t<0.
    \end{cases}
\]
总之，很容易验证
\eq{
    \int_{t_0}^t\d{t_1}\cdots\int_{t_0}^{t_{n-1}}\d{t_n} \hat H_1(t_1)\cdots\hat H_1(t_n) = \frac{1}{n!}\int_{t_0}^t\d{t_1}\cdots\int_{t_0}^{t}\d{t_n} \Tord[\hat H_1(t_1)\cdots\hat H_1(t_n)].
}
因而
\eq{
    U(t,t_0) = \Tord\exp(-\frac{\i}{\hbar}\int_{t_0}^t\d{t'} \hat H_1(t')),
}
这个级数也称\textbf{Dyson 级数}，因为他将其广泛应用于后续的量子电动力学中。

在散射问题中，假设 $\hat H_1$ 足够弱，粒子在远过去尚未相遇，在远未来又彼此分离，相互作用在 $t\to\pm\infty$ 时可忽略，体系渐近为自由态。设 $\ket{\alpha},\ket{\beta}$ 是 $\hat H_0$ 的本征态，比如连续动量本征态。
相互作用绘景自由态无需演化，因为 Schr\"odinger 绘景自由态演化为 $\e^{-\frac{\i}{\hbar}\hat H_0 t}\ket{\alpha}$，转换到相互作用绘景就是 $\e^{\frac{\i}{\hbar}\hat H_0 t}\e^{-\frac{\i}{\hbar}\hat H_0 t}\ket{\alpha}=\ket{\alpha}$，态矢的确只承载相互作用的影响。
定义 M\o ller 算符
\[
    \Omega_{\mathrm{in}}
    :=U(0,-\infty)=V^\dagger(-\infty),\quad
    \Omega_{\mathrm{out}}
    :=U(0,+\infty)=V^\dagger(+\infty).
\]
\textbf{出入射散射态}就是参考时刻 $t=0$ 的相互作用绘景态矢
\[
    \ket{\alpha,\mathrm{in}}:=\Omega_{\mathrm{in}}\ket{\alpha},\quad
    \ket{\beta,\mathrm{out}}:=\Omega_{\mathrm{out}}\ket{\beta}.
\]
它渐近于自由态，故也称\textbf{渐近态}(asymptotic state)。
\textbf{散射算符}将入射的自由数据映为出射的自由数据：
\eq{
    S:=\Omega_{\mathrm{out}}^\dagger\Omega_{\mathrm{in}}
    =U(+\infty,-\infty)
    =\Tord\exp[-\frac{\i}{\hbar}
    \int\d{t}\,\hat H_1(t)].
}
$S$ 在自由态基底下的矩阵元称为\textbf{$S$ 矩阵元}：
\eq{
    S_{\beta\alpha}
    :=\mel{\beta}{S}{\alpha}
    =\ip{\beta,\mathrm{out}}{\alpha,\mathrm{in}}.
}
它是入射道 $\alpha$ 跃迁至出射道 $\beta$ 的概率振幅；在渐近完备的情形下 $S$ 幺正，$S^\dagger S=1$。
若相互作用较弱，可将 Dyson 级数按 $\hat H_1$（或耦合常数）逐阶展开，并在给定阶数截断；忽略高阶项所得的近似即为\textbf{微扰近似}。
为了分离未发生散射的恒等部分与真正的跃迁部分，可将散射算符写为
\eq{
S=1+\i T,
\qquad
S_{\beta\alpha}
=\ip{\beta}{\alpha}
+\i\mel{\beta}{T}{\alpha}.
}
其中对于连续谱 $\ip{\beta}{\alpha}=\delta(\beta-\alpha)$。
这里 \textbf{$T$ 算符}表示 $S$ 算符中的非平凡跃迁部分。

由 $S-1=-\frac{\i}{\hbar}\int\d{t}\,\hat H_1(t)U(t,-\infty)$ 和 $\hat H_0\ket{\alpha}=E_\alpha\ket{\alpha},\hat H_0\ket{\beta}=E_\beta\ket{\beta}$，有
\[
U(t,-\infty)\ket{\alpha}=U(t,0)\ket{\alpha,\mathrm{in}}=\e^{\frac{\i}{\hbar}\hat H_0t}\e^{-\frac{\i}{\hbar}E_\alpha t}\ket{\alpha,\mathrm{in}},
\]
因此
\[
\mel{\beta}{\hat H_1(t)U(t,-\infty)}{\alpha}=
\e^{\frac{\i}{\hbar}(E_\beta-E_\alpha)t}
\mathcal T_{\beta\alpha}(E_\alpha),\quad
\mathcal T_{\beta\alpha}(E) := \mel{\beta}{\mathcal T(E)}{\alpha},
\]
其中以 $\mathcal T(E_\alpha)\ket{\alpha}:=\hat H_1\ket{\alpha,\mathrm{in}}$ 定义\textbf{在壳跃迁算符}。
代回时间积分：
\[
S_{\beta\alpha}-\ip{\beta}{\alpha}=
-\frac{\i}{\hbar}
\int\d{t}\,
\e^{\frac{\i}{\hbar}(E_\beta-E_\alpha)t}
\mathcal T_{\beta\alpha}(E_\alpha)=
-2\pi\i\,
\delta(E_\beta-E_\alpha)
\mathcal T_{\beta\alpha}(E_\alpha),
\]
故
\eq{
\i\mel{\beta}{T}{\alpha}=-2\pi\i\delta(E_\beta-E_\alpha)\mathcal T_{\beta\alpha}(E_\alpha).
}
其中 $\delta(E_\beta-E_\alpha)$ 体现定态散射中的能量守恒，而 $\mathcal T_{\beta\alpha}$ 包含具体相互作用所决定的散射动力学。

到底如何由 $\hat H_1$ 算出 $\mathcal T(E)$？很容易知道\textbf{交织关系}
\[ \hat H\Omega_{\mathrm{in/out}} = \Omega_{\mathrm{in/out}}\hat H_0. \]
考虑 $\ket{\alpha,\mathrm{in/out}} = \Omega_{\mathrm{in/out}}\ket{\alpha}$ 以统一讨论 $\ket{\alpha,\mathrm{in}},\ket{\beta,\mathrm{out}}$，则
\[\hat H\ket{\alpha,\mathrm{in/out}} =\hat H\Omega_{\mathrm{in/out}}\ket{\alpha}=\Omega_{\mathrm{in/out}}\hat H_0\ket{\alpha}=E_\alpha\Omega_{\mathrm{in/out}}\ket{\alpha}=E_\alpha\ket{\alpha,\mathrm{in/out}}.\]
故散射态与自由态虽然是不同哈氏量的本征态，但具有相同能量本征值，即 M\o ller 算符保持能量标签。物理上，这是因为所讨论的哈氏量不显含时间，散射过程中总能量守恒。相互作用会改变波函数、动量方向和散射道，却不会改变定态散射的总能量。这里的“相同能量”正是渐近自由态与精确散射态进行匹配的条件。
综上，写下散射态满足的方程
\eq{
    (E_\alpha-\hat H_0)\ket{\alpha,\mathrm{in/out}}
    =\hat H_1\ket{\alpha,\mathrm{in/out}}.
}
由于 $E_\alpha$ 位于 $\hat H_0$ 连续谱上，$E_\alpha-\hat H_0$ 不可直接求逆。引入带边界条件的自由\textbf{预解算符}(resolvent)
\eq{
    G_0^{\pm}(E)
    :=\lim_{\epsilon\to0^+}
    \frac{1}{E-\hat H_0\pm\i\epsilon}.
}
以下可省略 $\lim_{\epsilon\to0^+}$。
通解还包含齐次方程 $(E_\alpha-\hat H_0)\ket{\alpha}=0$ 的自由平面波解，得\textbf{Lippmann-Schwinger 方程}
\eq{
    \ket{\alpha,\mathrm{in/out}}
    =\ket{\alpha}+G_0^\pm(E_\alpha)\hat H_1\ket{\alpha,\mathrm{in/out}}.
}
我们之前用 $\ket{\alpha,\mathrm{in}}$ 定义 $\mathcal T(E)$，于是
\eq{
\mathcal T(E)=\hat H_1+\hat H_1G_0^{+}(E)\mathcal T(E)=\hat H_1+\hat H_1G_0^{+}(E)\hat H_1+\cdots.
}
这称为\textbf{Born 级数}。

方程的另一种写法是谱分解。设 $\{\ket{\sigma}\}$ 是 $\hat H_0$ 的连续谱完备本征态，满足 $1=\int\d{\sigma}\op{\sigma}$。
若 $\sigma$ 还包含离散量子数，$\int\d{\sigma}$ 约定也包含对它们求和。将完备关系插入预解算符，得到谱分解
\eq{
    G_0^\pm(E)
    =\int\d{\sigma}
    \frac{\op{\sigma}}{E-E_\sigma\pm\i\epsilon}.
}
于是
\[
    \ket{\alpha,\mathrm{in}}
    =\ket{\alpha}
    +\int\d{\sigma}\ket{\sigma}
    \frac{\mel{\sigma}{\hat H_1}{\alpha,\mathrm{in}}}
    {E_\alpha-E_\sigma+\i\epsilon},\quad
    \ket{\alpha,\mathrm{out}}
    =\ket{\alpha}
    +\int\d{\sigma}\ket{\sigma}
    \frac{\mel{\sigma}{\hat H_1}{\alpha,\mathrm{out}}}
    {E_\alpha-E_\sigma-\i\epsilon}.
\]
如果方程左乘某个 $\hat H_0$ 本征态 $\bra{\beta}$，则
\[
    \ip{\beta}{\alpha,\mathrm{in/out}}=\ip{\beta}{\alpha} +\frac{1}{E_\alpha-E_\beta\pm\i\epsilon} \mel{\beta}{\hat H_1}{\alpha,\mathrm{in/out}}.
\]
但如果不是本征态，比如取坐标表象，则
\[
    \psi_{\alpha,\mathrm{in/out}}(\bm r) = \phi_\alpha(\bm r) + \int\d[3]{r'}\mel{\bm r}{G_0^{\pm}(E_\alpha)}{\bm r'} (\hat H_1\psi_{\alpha,\mathrm{in/out}})(\bm r').
\]
其中 $\phi_\alpha(\bm r):=\ip{\bm r}{\alpha}$ 是平面波。
考虑非相对论二体运动，取\textbf{质心系}最为简单：
\[
    M=m_1+m_2,\quad \mu=\frac{m_1m_2}{M},\quad
    \bm R=\frac{m_1\bm r_1+m_2\bm r_2}{M},\quad
    \bm r=\bm r_1-\bm r_2,
\]
$\mu$ 称为约化质量。并定义总动量和相对动量
\[
    \bm P=\bm p_1+\bm p_2,\quad
    \bm p=\mu\left(\frac{\bm p_1}{m_1}-\frac{\bm p_2}{m_2}\right).
\]
若相互作用仅依赖相对坐标，则
\[
    \hat H=\frac{\hat{\bm P}^2}{2M}
    +\frac{\hat{\bm p}^2}{2\mu}+V(\hat{\bm r}).
\]
质心系中 $\bm P=\bm 0$，两体散射遂化为质量为 $\mu$ 的单粒子散射，散射角就是入射与出射相对动量之间的夹角。
自由项是 $\hat H_0=\hat{\bm p}^2/2\mu$，势能项是 $\hat H_1=V(\hat{\bm r})$，坐标表象也就是 $\hat H_1\psi(\bm r)=V(\bm r)\psi(\bm r)$，显然动量本征态的确也是 $\hat H_0$ 本征态。
波矢模长为 $k=\sqrt{2\mu E}/\hbar$。
自由预解算符的坐标表象为
\eq{
    \mel{\bm r}{G_0^{\pm}(E)}{\bm r'}
    = \int\frac{\d[3]{p}}{(2\pi\hbar)^3}\frac{\e^{\pm\i\bm p\cdot(\bm r-\bm r')/\hbar}}{E-\frac{\bm p^2}{2\mu}\pm\i\epsilon}  = -\frac{\mu}{2\pi\hbar^2}
    \frac{\e^{\pm\i k|\bm r-\bm r'|}}{|\bm r-\bm r'|}.
}
$\e^{\pm\i k r}/r$ 就是出射、入射的球面波的形式，因为演化 $\e^{-\i \omega t}\e^{\pm\i k r}/r$ 的波峰随时间分别向更大、更小的 $r$ 传播。
因此 $G_0^+$ 产生出射球面波并规定入态，$G_0^-$ 产生入射球面波并规定出态。


对于 $\beta\ne\alpha$ 的真正跃迁，恒等算符没有贡献，概率振幅就是 $\mel{\beta}{\i T}{\alpha}$。若初、末态未归一化，按照 Born 规则，跃迁概率应写为
\eq{
    P_{\alpha\to\beta}
    =\frac{|\mel{\beta}{\i T}{\alpha}|^2}
    {\ip{\alpha}\ip{\beta}}
    =\frac{4\pi^2\delta^2(E_\beta-E_\alpha)
    |\mathcal T_{\beta\alpha}(E_\alpha)|^2}
    {\ip{\alpha}\ip{\beta}}.
}
归一化波包的分母为 $1$；动量本征态则是广义本征态，分母含有 $\delta(\bm 0)$，不能省略。此外，上式还出现了能量 Dirac 函数的平方。设相互作用持续时间为 $\tau$，由
\eq{
    2\pi\hbar\delta(E)
    =\lim_{\tau\to\infty}
    \int_{-\tau/2}^{\tau/2}\d{t}\,
    \e^{\frac{\i}{\hbar}Et},\quad
    \delta(0)=\frac{\tau}{2\pi\hbar},
}
可将它理解为
\eq{
    \delta^2(E_\beta-E_\alpha)
    =\frac{\tau}{2\pi\hbar}\delta(E_\beta-E_\alpha).
}
因此，先将振幅模方除以初、末态的归一化因子得到概率，再将这一概率除以作用时间，得到单位时间的跃迁概率
\eq{
    \Gamma_{\alpha\to\beta}
    :=\frac{P_{\alpha\to\beta}}{\tau}
    =\frac{2\pi}{\hbar}
    \frac{|\mathcal T_{\beta\alpha}(E_\alpha)|^2}
    {\ip{\alpha}\ip{\beta}}
    \delta(E_\beta-E_\alpha).
}
对于连续末态，还要对实验无法分辨的末态求和。把末态归一化因子吸收到末态数 $\d{\rho_\beta}$ 中，并取归一化的初态，便有
\eq{
    \d{\Gamma_{\alpha\to\beta}}
    =\frac{2\pi}{\hbar}|\mathcal T_{\beta\alpha}(E_\alpha)|^2
    \delta(E_\beta-E_\alpha)\d{\rho_\beta}.
}
这就是 Fermi 黄金律的散射形式。可见，$S$ 矩阵元的模方首先给出跃迁概率，除以作用时间后才得到跃迁率。

考虑非相对论两体散射。沿用前文质心系中的相对坐标和约化质量，并将入射波振幅取为 $1$。从入射道 $\alpha$ 到出射道 $\beta$ 的渐近波函数为
\eq{
    \psi(\bm r)\xrightarrow{r\to\infty}
    \e^{\frac{\i}{\hbar}\bm p_\alpha\vdot\bm r}
    +f_{\beta\alpha}(\Omega)
    \frac{\e^{\frac{\i}{\hbar}p_\beta r}}{r}.
}
第一项是入射平面波，第二项是出射球面波，其系数 $f_{\beta\alpha}(\Omega)$ 称为\textbf{散射振幅}。对于单道弹性散射，$p_\alpha=p_\beta=p$；沿用 $\ip{\bm p'}{\bm p}=\delta(\bm p'-\bm p)$，有
\eq{
    f(\bm p',\bm p)
    =-4\pi^2\mu\hbar
    \mel{\bm p'}{\mathcal T(E+\i\epsilon)}{\bm p},\quad
    E=\frac{p^2}{2\mu},\quad \bm p'=p\hat{\bm r}.
}

实验上常用\textbf{束流打靶}：大量入射粒子形成束流，轰击近似静止的靶粒子，再统计各方向的出射粒子。散射道 $\gamma$ 的概率流密度为
\eq{
    \bm j_\gamma
    =\frac{\hbar}{2\mu_\gamma\i}
    (\psi_\gamma^*\grad\psi_\gamma
    -\psi_\gamma\grad\psi_\gamma^*),\quad
    v_\gamma=\frac{p_\gamma}{\mu_\gamma}.
}
若束流的粒子数密度为 $n_{\mathrm b}$，其入射流密度为
\eq{
    \Phi_{\mathrm{in}}=n_{\mathrm b}v_{\mathrm{rel}},\quad
    v_{\mathrm{rel}}=|\bm v_1-\bm v_2|=\frac{p_\alpha}{\mu_\alpha}.
}
固定靶实验中 $\bm v_2=0$。若靶中有 $N_{\mathrm T}$ 个彼此独立的散射中心，则以跃迁率除以入射流密度
\eq{
    \Gamma_{\mathrm{sc}}=N_{\mathrm T}\Phi_{\mathrm{in}}\sigma
}
定义\textbf{散射截面} $\sigma$，其量纲为面积；进一步定义\textbf{微分截面}
\eq{
    \dv{\sigma}{\Omega}
    :=\frac{1}{N_{\mathrm T}\Phi_{\mathrm{in}}}
    \dv{\Gamma_{\mathrm{sc}}}{\Omega},\quad
    \sigma=\int\d{\Omega}\dv{\sigma}{\Omega}.
}
将上述渐近波代入概率流公式，入射流和出射球面波的径向流分别为
\eq{
    j_{\mathrm{in}}=v_\alpha,\quad
    j_{\mathrm{sc}}^{(r)}
    =\frac{v_\beta}{r^2}|f_{\beta\alpha}(\Omega)|^2.
}
立体角 $\d\Omega$ 对应球面面积 $r^2\d\Omega$。微分截面就是单位入射流所产生的出射流，因而
\eq{
    \dv{\sigma_{\beta\leftarrow\alpha}}{\Omega}
    =\frac{r^2j_{\mathrm{sc}}^{(r)}}{j_{\mathrm{in}}}
    =\frac{v_\beta}{v_\alpha}|f_{\beta\alpha}(\Omega)|^2.
}
对于弹性散射，$v_\beta=v_\alpha$，故 $\dv*{\sigma}{\Omega}=|f(\Omega)|^2$。

固定靶实验中，一部分动能用于质心整体运动；若质量为 $m_1$ 的粒子轰击静止的质量为 $m_2$ 的靶，其可用于相对运动的能量为
\eq{
    E_{\mathrm{cm}}=\frac{1}{2}\mu v_{\mathrm{rel}}^2
    =\frac{m_2}{m_1+m_2}E_{\mathrm{lab}}.
}
\textbf{对撞机}令两束粒子反向运动，可使质心近似静止，从而将更多束流能量用于相对运动和散射过程。两束粒子数密度分别为 $n_1,n_2$ 时，事件率仍可写成
\eq{
    \Gamma_{\mathrm{sc}}=\mathcal L\sigma,\quad
    \mathcal L:=\int\d[3]{x}\,n_1(\bm x)n_2(\bm x)v_{\mathrm{rel}},
}
其中 $\mathcal L$ 称为\textbf{亮度}。不过实际对撞机中的粒子速度通常接近光速，此时上述非相对论公式不再适用，必须改用相对论运动学，后续再讨论。

\section{路径积分量子化}

所谓量子，就是将经典物理量提升为非对易算符，再用态矢或波函数描述概率振幅，概率振幅的平方解释为概率密度。Schr\"odinger 绘景的态矢在 $t_a,t_b$ 的演化为 $\ket{\psi(t_b)}=\hat U(t_b,t_a)\ket{\psi(t_a)}$。插入初始的位置完备关系 $\int\d[3]{x_a}\op{\bm x_a}=1$，得到
\begin{align}
    \ket{\psi(t_b)}&=\int\d[3]{x_a}\hat U(t_b,t_a)\ket{\bm x_a} \ip{\bm x_a}{\psi(t_a)},\\
    \psi(\bm x_b,t_b) & = \int\d[3]{x_a} \mel{\bm x_b}{\hat U(t_b,t_a)}{\bm x_a} \psi(\bm x_a,t_a).
\end{align}
其中有时也记 $K(\bm x_b,t_b;\bm x_a,t_a) := \mel{\bm x_b}{\hat U(t_b,t_a)}{\bm x_a}$，正是粒子从 $(x_a,t_a)$ 到 $(x_b,t_b)$ 的概率振幅，称为\textbf{Feynman 核}。也可看做演化算符在坐标表象的矩阵元。
如果我们知道 Feynman 核，就可以根据积分由初始波函数求得末态波函数。这种做法与求解 Schrödinger 方程是等价的。
由于 $\hat H$ 不含时，则 $\hat H_H=\hat H$，因此演化算符也一致，从而 $\hat A_H(t)=\e^{\frac{\i}{\hbar}\hat H t}\hat A_S\e^{-\frac{\i}{\hbar}\hat H t}$，这里取 $t_0=0$ 的 Heisenberg 绘景。
定义 $\ket{\bm x,t}:=\e^{\frac{\i}{\hbar}\hat H t}\ket{\bm x}$，计算知它是 $\hat{\bm x}_H(t)$ 在 $t$ 的瞬时本征态：$\hat{\bm x}_H(t)\ket{\bm x,t}=\bm x\ket{\bm x,t}$。由于 $\e^{\frac{\i}{\hbar}\hat H t}$ 是幺正的，显然 $\{\ket{\bm x,t}\}$ 仍然是 $\{\ket{\bm x}\}$ 的完备的正交归一基：
\[\ip{\bm x,t}{\bm y,t}=\delta(\bm x-\bm y),\quad \int\d[3]{x}\op{\bm x,t}=1.\]
注意 $\ket{\Psi_H}=\e^{\frac{\i}{\hbar}\hat H t}\ket{\Psi(t)}$，则波函数满足 $\Psi(\bm x,t) = \ip{\bm x}{\Psi(t)} = \ip{\bm x,t}{\Psi_H}$，因此 Feynman 核也可以看做 Heisenberg 绘景下，瞬时位置本征态的内积 $\ip{\bm x_b,t_b}{\bm x_a,t_a}$。如此，我们就更能看清楚，它的确是从 $t_a$ 时刻态矢 $\ket{\bm x_a,t_a}$ 到 $t_b$ 时刻态矢 $\ket{\bm x_b,t_b}$ 的跃迁振幅。


%% $\hat A_H(t)=\int\d[3]{x}\d[3]{y} \ket{\bm x,t}\mel{\bm x}{\hat A_S}{\bm y}\bra{\bm y,t}$

如果关注于概率振幅的路径依赖性，那么可以将把量子理论改写为另一种形式：对所有可能的历史求和。这一方法称为\textbf{路径积分}(path integral)法。换言之，Schr\"odinger 方法关注于如何求解给定的 $\hat H$ 方程，路径积分则关注于如何计算 Feynman 核。
我们曾在经典力学中学习过最小作用量原理。路径积分可以对此有一个进一步的解释。
量子粒子从初始点运动到末点时，并非只选取某一条经典轨道，而是所有可能路径都对概率振幅有贡献；每条路径的贡献是一个相位，其相位由该路径的作用量决定。经典轨道之所以在宏观极限下显得特殊，是因为它附近的相位相干叠加，而远离经典轨道的路径相位快速振荡，彼此抵消。

为使化简方便一些，我们采取这样一种动量本征矢约定，与之前的定义相差因子：
\eq{
    \int \frac{\d[3]{p}}{(2\pi\hbar)^3}\op{\bm p}:=1 \im \ip{\bm p}{\bm p'} = (2\pi\hbar)^3\delta(\bm p-\bm p'),\quad \ip{\bm x}{\bm p} = \e^{\frac{\i}{\hbar}\bm p\cdot\bm x}.
}
对时间间隔进行划分：
\[
    \epsilon=\frac{t_b-t_a}{N},\quad t_j=t_a+j\epsilon,
\]
其中 $j=0,\cdots,N$，并记 $\bm x_0=\bm x_a, \bm x_N=\bm x_b$。
插入完备关系来分解 Feynman 核：
\[
    \ip{\bm x_b,t_b}{\bm x_a,t_a}=\int \prod_{j=1}^{N-1}\d[3]{x_j} \prod_{j=0}^{N-1} \ip{\bm x_{j+1},t_{j+1}}{\bm x_j,t_j}.
\]
或者仍然采取\footnote{哈氏量不含时。若哈氏量含时，则严格地说需要时间排序，但路径积分的基本构造仍可由把时间切成许多小段来理解。} $\hat U(t_b,t_a)=\e^{-\frac{\i}{\hbar}\hat H(t_b-t_a)}$，将其分解为乘积，相邻插入位置完备关系即可。
可见固定端点后积分变量 $\bm x_1,\cdots,\bm x_{N-1}$ 枚举了粒子在中间时刻可能经过的位置。当 $N\to\infty$ 时，这些离散点连成一条路径 $\bm x(t)$，这时 $\ip{\bm x_{j+1},t_{j+1}}{\bm x_j,t_j} = \mel{\bm x_{j+1}}{\e^{-\frac{\i}{\hbar}\epsilon\hat H}}{\bm x_j}$ 称为\textbf{短时 Feynman 核}。即
\eq{
    \ip{\bm x_b,t_b}{\bm x_a,t_a} = \lim_{N\to\infty} \int\prod_{j=1}^{N-1}\d[3]{x_j} \prod_{j=0}^{N-1} \mel{\bm x_{j+1}}{\e^{-\frac{\i}{\hbar}\epsilon\hat H}}{\bm x_j}.
}
直接计算初末的完整 Feynman 核比较麻烦，但如果只是想读出哈氏量，其实只需要短时 Feynman 核，相对就简单些，因为 $\exp(-\frac{\i}{\hbar}\epsilon\hat H)=1 - \frac{\i}{\hbar}\epsilon\hat H + O(\epsilon^2)$。
将短时 Feynman 核展开到一阶 $\mel{\bm x_{j+1}}{\e^{-\frac{\i}{\hbar}\epsilon\hat H}}{\bm x_j} = \ip{\bm x_{j+1}}{\bm x_j} - \frac{\i}{\hbar}\epsilon\mel{\bm x_{j+1}}{\hat H}{\bm x_j} + O(\epsilon^2)$ 就能读出哈氏量的形式。
插入动量完备关系：
\[
    \mel{\bm x_{j+1}}{\hat H}{\bm x_j} = \int\frac{\d[3]{p_j}}{(2\pi\hbar)^3} \e^{\frac{\i}{\hbar}\bm p_j\vdot \bm x_{j+1}} \mel{\bm p_j}{\hat H}{\bm x_j},
\]
通常 $\hat H$ 是 $\hat{\bm x},\hat{\bm p}$ 的多项式。对于上式右边的 $\mel{\bm p_j}{\hat H}{\bm x_j}$，只要拿 $\hat H$ 中的 $\hat{\bm x}$ 算符往右作用到 $\ket{\bm x_j}$ 上、$\hat{\bm p}$ 算符往左作用到 $\bra{\bm p_j}$ 上，就能得到相应的本征值 $\bm x_j,\bm p_j$，从而将算符 $\hat H$ 转化成经典函数 $H$。然而，由于 $\hat{\bm x},\hat{\bm p}$ 不对易，$\hat H$ 中 $\hat{\bm x},\hat{\bm p}$ 的排列次序会影响计算结果。
在此，如果假设哈氏量中 $\hat{\bm x},\hat{\bm p}$ 的排序遵循所谓的\textbf{Weyl 排序}，则可经过一些计算得
\eq{
    \mel{\bm x_{j+1}}{\hat H}{\bm x_j} = \int\frac{\d[3]{p_j}}{(2\pi\hbar)^3} \e^{\frac{\i}{\hbar}\bm p_j\vdot(\bm x_{j+1}-\bm x_j)} H(\bar{\bm x}_j,\bm p_j),\quad \bar{\bm x}_j=\frac{\bm x_{j+1}+\bm x_j}{2}.
}
注意 $\ip{\bm x_{j+1}}{\bm x_j}=\delta(\bm x_{j+1}-\bm x_j) = \int\frac{\d[3]{p_j}}{(2\pi\hbar)^3} \e^{\frac{\i}{\hbar}\bm p_j\vdot(\bm x_{j+1}-\bm x_j)}$，从而
\begin{align*}
    \mel{\bm x_{j+1}}{\e^{-\frac{\i}{\hbar}\epsilon\hat H}}{\bm x_j} &= \int\frac{\d[3]{p_j}}{(2\pi\hbar)^3} \e^{\frac{\i}{\hbar}\bm p_j\vdot(\bm x_{j+1}-\bm x_j)} \left(1 - \frac{\i}{\hbar}\epsilon H\right) + O(\epsilon^2)\\
    &= \int\frac{\d[3]{p_j}}{(2\pi\hbar)^3} \exp(\frac{\i}{\hbar}\epsilon \left(\bm p_j\vdot\frac{\bm x_{j+1}-\bm x_j}{\epsilon}-H\right)) + O(\epsilon^2),
\end{align*}
即
\begin{align}
    \ip{\bm x_b,t_b}{\bm x_a,t_a} &= \lim_{N\to\infty} \int\prod_{j=1}^{N-1}\d[3]{x_j} \prod_{j=0}^{N-1} \frac{\d[3]{p_j}}{(2\pi\hbar)^3} \exp(\frac{\i}{\hbar}\epsilon\sum_{j=0}^{N-1}\left(\bm p_j\vdot\frac{\bm x_{j+1}-\bm x_j}{\epsilon}-H\right)),\notag \\
    &=: \tcbhighmath{\int_{\bm x(t_a)=\bm x_a}^{\bm x(t_b)=\bm x_b}
    \mathcal D\bm x\,\mathcal D\bm p\,
    \exp(
        \frac{\i}{\hbar}
        \int_{t_a}^{t_b}\d{t}
        \left[\bm p\cdot\dot{\bm x}-H(\bm x,\bm p)\right]
    ).}
\end{align}
这称为\textbf{相空间形式的路径积分}。由于这是对任意路径遍历，因此至少在形式上是泛函的积分，但 $\mathcal D\bm x\,\mathcal D\bm p$ 不是普通有限维积分测度，而是上述离散化极限的简写。严格上来说无穷维函数空间很难有良定义的测度，但在物理上一般总采取离散方法去计算路径积分，因此 $\mathcal D$ 可以仅作为形式记号。在路径积分表达式中，只涉及到演化算符，不涉及 Hilbert 空间上
的算符和态矢，但积分结果却给出了像 Feymnan 核这样的量子跃迁振幅，已然实现了量子化，但显式上避开了算符或态矢。
这样的量子化方法称为\textbf{路径积分量子化}。

先给出 Gauss 路径积分的形式公式。设 $A$ 是对称可逆的核，并记
\eq{
    \xi A\xi:=\int\d{t}\d{t'}\,\xi(t)A(t,t')\xi(t'),\quad
    J\xi:=\int\d{t}\,J(t)\xi(t).
}
配方得到
\eq{
    -\frac{1}{2}\xi A\xi+J\xi
    =-\frac{1}{2}(\xi-A^{-1}J)A(\xi-A^{-1}J)
    +\frac{1}{2}JA^{-1}J.
}
为说明从普通积分到路径积分的过渡，将时间区间离散成 $N$ 个积分变量，并把时间步长吸收到矩阵和向量的定义中：
\eq{
    \xi(t)\longrightarrow\bm\xi=(\xi_1,\ldots,\xi_N)^\mathrm T,
    \quad \xi A\xi\longrightarrow\bm\xi^\mathrm T A_N\bm\xi,
    \quad J\xi\longrightarrow\bm J_N^\mathrm T\bm\xi,
    \quad \mathcal D\xi\longrightarrow C_N\d[N]{\xi}.
}
于是路径积分在有限 $N$ 时由普通多重积分近似：
\eq{
    I_N[\bm J_N]
    :=C_N\int\d[N]{\xi}\,
    \exp\{\frac{\i}{\hbar}
    [-\frac{1}{2}\bm\xi^\mathrm T A_N\bm\xi
    +\bm J_N^\mathrm T\bm\xi]\}.
}
令 $\bm\eta:=\bm\xi-A_N^{-1}\bm J_N$。这是平移变换，Jacobi 行列式为 $1$，故 $\d[N]{\xi}=\d[N]{\eta}$。有限维的配方是严格的，因而
\[
    I_N[\bm J_N]
    =C_N\exp(\frac{\i}{2\hbar}
    \bm J_N^\mathrm T A_N^{-1}\bm J_N)
    \int\d[N]{\eta}\,
    \exp(-\frac{\i}{2\hbar}\bm\eta^\mathrm T A_N\bm\eta)=:\mathcal N_{A,N}\exp(\frac{\i}{2\hbar}
    \bm J_N^\mathrm T A_N^{-1}\bm J_N).
\]
余下的积分与 $\bm J_N$ 无关。根据 Fresnel--Gauss 公式\footnote{严格地说，实时积分是振荡积分，需要加入 $\i\epsilon$ 并选定平方根分支。若矩阵不定，还会出现由其符号差决定的 Fresnel 相位。}
\eq{
    \int \d[n]{\eta}\,
    \exp(\frac{\i}{2}\bm\eta^\mathrm T B\bm\eta)
    =\frac{(2\pi\i)^{n/2}}{\sqrt{\det B}},
}
可知 $\mathcal N_{A,N}\propto(\det A_N)^{-1/2}$，比例系数由测度 $C_N$ 和 $\i\epsilon$ 规定决定。
最后令时间步长趋于零。此时 $A_N^{-1}$ 趋于逆核 $A^{-1}$，满足
\eq{
    \int\d{t''}\,A(t,t'')A^{-1}(t'',t')=\delta(t-t'),
}
并且 $\bm J_N^\mathrm T A_N^{-1}\bm J_N\to JA^{-1}J$。将 $\mathcal N_A:=\lim_{N\to\infty}\mathcal N_{A,N}$ 作为形式归一化因子，便得到\textbf{Gauss 路径积分}
\eq{
    \int\mathcal D\xi\,
    \e^{\frac{\i}{\hbar}(-\frac{1}{2}\xi A\xi+J\xi)}
    =\mathcal N_A\,
    \e^{\frac{\i}{2\hbar}JA^{-1}J},\quad
    \mathcal N_A:=\int\mathcal D\xi\,
    \e^{-\frac{\i}{2\hbar}\xi A\xi}.
}
连续极限中的 $\det A$ 称为泛函行列式，只作离散极限意义下的形式理解。可见，平移积分变量将所有 $J$ 依赖性集中到 $JA^{-1}J/2$，而 $\mathcal N_A$ 只负责归一化。

现在取非相对论哈氏量 $\hat H=\hat{\bm p}^2/2m+V(\hat{\bm x})$。相空间作用量关于 $\bm p$ 是二次型，在上式中令
\[
    A(t,t')=\frac{1}{m}\delta(t-t'),\quad
    J(t)=\dot{\bm x}(t),\quad
    A^{-1}(t,t')=m\delta(t-t'),
\]
立即得到
\[
    \int\mathcal D\bm p\,
    \exp[\frac{\i}{\hbar}\int\d{t}
    \left(\bm p\vdot\dot{\bm x}-\frac{\bm p^2}{2m}\right)]
    =\mathcal N_p
    \exp[\frac{\i}{\hbar}\int\d{t}\,\frac{m}{2}\dot{\bm x}^2].
\]
离散化后，这一归一化因子正是各时间片上普通 Gauss 积分的乘积：
\[
    \int \frac{\d[3]{p_j}}{(2\pi\hbar)^3}
    \exp[-\frac{\i\epsilon}{2m\hbar}
    (\bm p_j-m\dot{\bm x}_j)^2]
    =\left(\frac{m}{2\pi\i\hbar\epsilon}\right)^{3/2},\quad
    \dot{\bm x}_j=\frac{\bm x_{j+1}-\bm x_j}{\epsilon}.
\]
于是得\textbf{坐标空间的路径积分}
\begin{align}
    \ip{\bm x_b,t_b}{\bm x_a,t_a}&=
    \tcbhighmath{
    \int_{\bm x(t_a)=\bm x_a}^{\bm x(t_b)=\bm x_b}
    \mathcal D \bm x\, \e^{\frac{\i}{\hbar}S[\bm x]},
    }\\
    &=\lim_{N\to\infty}
    \left(\frac{m}{2\pi\i\hbar\epsilon}\right)^{3N/2}
    \int\prod_{j=1}^{N-1}\d[3]{x_j}
    \exp(
        \frac{\i}{\hbar}\epsilon
        \sum_{j=0}^{N-1}
        \left[
            \frac{m}{2}\dot{\bm x}_j^2
            -V(\bar{\bm x}_j)
        \right]
    ), \notag
\end{align}
其中经典作用量为 $S=\int_{t_a}^{t_b}\d{t} L(\bm x,\dot{\bm x}),L=\frac{1}{2}m\dot{\bm x}^2-V(\bm x)$，归一化系数吸收进形式记号 $\mathcal D x$ 中。
此即从 $\bm x_a$ 到 $\bm x_b$ 的总振幅等于所有路径振幅的叠加，而每条路径 $\bm x(t)$ 的振幅为 $\e^{\frac{\i}{\hbar}S}$。
经典力学学过，考虑路径的 Fréchet 变分 $q(t)\to q(t)+\delta q(t),\delta q(t_a)=\delta q(t_b)=0$。
作用量的一阶变化为
\[\delta S
    =
    \int_{t_a}^{t_b}\d{t}
    \left(
        \pdv{L}{q}\delta q
        +\pdv{L}{\dot q}\delta\dot q
    \right) =
    \int_{t_a}^{t_b}\d{t}
    \left[
        \pdv{L}{q}
        -
        \dv{t}\left(\pdv{L}{\dot q}\right)
    \right]\delta q.\]
变分为零的充分必要条件是这个大括号为零，这就是 Euler-Lagrange 方程。
路径积分中相邻路径的相位差为 $\Delta\varphi={\Delta S}/{\hbar}$。
当 $\hbar$ 很小时，只要 $\Delta S$ 不是很小，相位就会迅速振荡，路径贡献彼此抵消；只有在 $\delta S=0$ 的经典路径附近，作用量变化缓慢，相位能够相干叠加。因此经典极限 $\hbar\to0$ 下，路径积分由经典路径主导。因而 Feynman 的路径积分量子化，能直接导出经典的最小作用量原理。

虽然系数 $\left({m}/{2\pi\i\hbar\epsilon}\right)^{3N/2}$ 发散，但整个式子仍收敛 —— 显然（经 $\i\epsilon$ 规定后的）Feynman 核有限！坐标积分应当有反因子与之相消。为直接计算来体现这一点，考虑自由粒子 $V=0$。由于 $\hat H=\hat{\bm p}^2/2m$ 只含 $\hat{\bm p}$，在动量表象中对角，于是 $\e^{-\frac{\i}{\hbar}\frac{\hat{\bm p}^2}{2m} (t_b-t_a)}\ket{\bm p}=\e^{-\frac{\i}{\hbar}\frac{{\bm p}^2}{2m} (t_b-t_a)}\ket{\bm p}$，故通常的办法是直接插入动量完备关系并应用普通 Gauss 积分得
\begin{align*}
\ip{\bm x_b,t_b}{\bm x_a,t_a}&=\mel{\bm x_b}{\e^{-\frac{\i}{\hbar}\hat H (t_b-t_a)}}{\bm x_a}=
\int \frac{\dd[3]{p}}{(2\pi\hbar)^3}
\exp(
\frac{\i}{\hbar}\bm p\cdot(\bm x_b-\bm x_a)
-\frac{\i}{\hbar}\frac{\bm p^2}{2m}(t_b-t_a))\\
&=\exp\frac{\i m(\bm x_b-\bm x_a)^2}{2\hbar (t_b-t_a)}
\int \frac{\dd[3]{q}}{(2\pi\hbar)^3}
\exp\frac{-\i(t_b-t_a)\bm q^2}{2m\hbar}\\
&=\left(\frac{m}{2\pi\i\hbar (t_b-t_a)}\right)^{3/2}
    \exp\frac{\i m(\bm x_b-\bm x_a)^2}{2\hbar (t_b-t_a)}.
\end{align*}
其中配方法取 $\bm q=\bm p-m\frac{\bm x_b-\bm x_a}{t_b-t_a}$。
下面从路径积分复核这一结果，并具体计算其归一化因子。
$V=0$ 使 $\mathcal D\bm x$ 部分也会类似于 Gauss 积分，即 $\frac{\i m\epsilon}{2\hbar}\left(\frac{\bm x_{j+1}-\bm x_j}{\epsilon}\right)^2=\frac{\i m}{2\hbar\epsilon}(\bm x_{j+1}-\bm x_j)^2$ 项。
当然，由于 $\prod_{j=1}$ 与 $\sum_{j=0}$ 不对应，且 $\bm x_{j+1}-\bm x_j$ 会产生交叉项，因此稍微复杂一些。
把路径 $\bm x=\bm x_\mathrm{cl}+\bm\eta$ 拆成经典直线路径 $\bm x_\mathrm{cl}=\bm x_a+\frac{\bm x_b-\bm x_a}{t_b-t_a}(t-t_a)$ 与涨落 $\bm\eta$，满足 $\bm\eta(t_a)=\bm\eta(t_b)=0$。
经典路径满足 $\ddot{\bm x}_\mathrm{cl}=0$，结合涨落的零端点条件，作用量中的交叉项消失。从而
\[
    \int_{\bm x(t_a)=\bm x_a}^{\bm x(t_b)=\bm x_b}
    \mathcal D\bm x\,
    \exp(\frac{\i m}{2\hbar}\int\d{t}\dot{\bm x}^2)=\exp\frac{\i m(\bm x_b-\bm x_a)^2}{2\hbar(t_b-t_a)}
    \int_{\bm\eta(t_a)=0}^{\bm\eta(t_b)=0}
    \mathcal D\bm\eta\,
    \exp(\frac{\i m}{2\hbar}\int\d{t}\dot{\bm\eta}^2).
\]
这正是前述 Gauss 路径积分公式在 $A=m\dv[2]{}{t}$ 及零端点边界条件下的应用。余下的涨落积分与端点无关，只决定归一化因子。
记这个涨落积分为 $F(t_b-t_a)$。分部积分并利用 $\bm\eta(t_a)=\bm\eta(t_b)=0$，可将其二次型写成
\[
    \frac{m}{2}\int_{t_a}^{t_b}\d{t}\,\dot{\bm\eta}^2
    =\frac{1}{2}\int_{t_a}^{t_b}\d{t}\,
    \bm\eta\left(-m\dv[2]{}{t}\right)\bm\eta\im F(t_b-t_a)=C\left[\det\nolimits_D
    \left(-\dv[2]{}{t}\right)\right]^{-3/2}.
\]
其中下标 $D$ 表示零端点的 Dirichlet 边界条件；与 $t_b-t_a$ 无关的 $m,\hbar$、测度归一化及 Fresnel 相位均暂时吸收到常数 $C$ 中。这个泛函行列式可由 Gel'fand--Yaglom 方法计算：求解
\[
    -\ddot y(t)=0,\quad y(t_a)=0,\quad \dot y(t_a)=1,
\]
得到 $y(t)=t-t_a$。该方法指出 Dirichlet 泛函行列式正比于 $y(t_b)$，故
\[
    \det\nolimits_D\left(-\dv[2]{}{t}\right)\propto t_b-t_a,\quad
    F(t_b-t_a)=C (t_b-t_a)^{-3/2}.
\]
于是自由粒子核必为 $\ip{\bm x_b,t_b}{\bm x_a,t_a}
    =C (t_b-t_a)^{-3/2}
    \exp\frac{\i m(\bm x_b-\bm x_a)^2}{2\hbar (t_b-t_a)}$。
最后用演化算符在零时间间隔退化为恒等算符，即
\eq{
    \lim_{t_b\to t_a^+}\ip{\bm x_b,t_b}{\bm x_a,t_a}
    =\delta(\bm x_b-\bm x_a).
}
对照 Dirac 函数的 Fresnel 表示
\eq{
    \delta(\bm x)
    =\lim_{t_b\to t_a^+}
    \left(\frac{m}{2\pi\i\hbar (t_b-t_a)}\right)^{3/2}
    \exp\frac{\i m\bm x^2}{2\hbar (t_b-t_a)},
}
确定 $C=(m/2\pi\i\hbar)^{3/2}$。
代回就得相同结果。

下面将 Feynman 核的路径积分表达代入波函数中，就可以得到 Schr\"odinger 方程，因此两种表述等价。根据 Feynman 核或者演化算符的拆分的组合律，其实也即完备性，显然只需用短时 Feynman 核给出 Schr\"odinger 方程即可。
取 $t_b=t+\epsilon$，$\bm x_b=\bm x$ 和 $\bm\eta=\bm x'-\bm x$，则
\begin{align*}
    \Psi(\bm x,t+\epsilon)
    &=
    \int\d[3]{\bm x'}\ip{\bm x,t+\epsilon}{\bm x',t}\psi(\bm x',t)\\
    &=
    \left(\frac{m}{2\pi\i\hbar\epsilon}\right)^{3/2}
    \int\d[3]{\bm\eta}
    \exp\left[
        \frac{\i m\bm\eta^2}{2\hbar\epsilon}
        -\frac{\i\epsilon}{\hbar}V(\bm x)
    \right]
    \psi(\bm x+\bm\eta,t),
\end{align*}
其中已在 $\epsilon\to0$ 的意义下把势能取在 $\bm x$ 处。由于 Gauss 因子主要约束 $\bm\eta^2\sim \epsilon$，展开
\eq{
    \psi(\bm x+\bm\eta,t)=\Psi(\bm x,t)+\bm\eta\pdv{\psi}{\bm x}
    +\frac{\bm\eta^2}{2}\pdv[2]{\psi}{\bm x}+\cdots,
}
以及 $\e^{-\frac{\i\epsilon}{\hbar}V(\bm x)}
    =
    1-\frac{\i\epsilon}{\hbar}V(\bm x)+\cdots$，
利用 Gauss 积分
\[
    \left(\frac{m}{2\pi\i\hbar\epsilon}\right)^{3/2}
    \int\d[3]{\bm\eta} 
    \e^{\frac{\i m\bm\eta^2}{2\hbar\epsilon}}=1,\quad
    \left(\frac{m}{2\pi\i\hbar\epsilon}\right)^{3/2}
    \int\d[3]{\bm\eta} 
    \bm\eta^2
    \e^{\frac{\i m\bm\eta^2}{2\hbar\epsilon}}
    =
    \frac{\i\hbar\epsilon}{m},
\]
奇函数项积分为零，于是
\eq{
    \Psi(\bm x,t+\epsilon)
    =
    \Psi(\bm x,t)
    +\frac{\i\hbar\epsilon}{2m}\pdv[2]{\psi}{\bm x}
    -\frac{\i\epsilon}{\hbar}V(\bm x)\Psi(\bm x,t)
    +O(\epsilon^2).
}
另一方面
\eq{
    \Psi(\bm x,t+\epsilon)=\Psi(\bm x,t)+\epsilon\pdv{\psi}{t}+O(\epsilon^2).
}
比较两式并乘以 $\i\hbar$，得 Schr\"odinger 方程。

\subsection{关联函数}

考虑线性方程
\eq{
    \hat L\ket{u}=\ket{f}.
}
取坐标表象 $u(x):=\ip{x}{u}$、$f(x):=\ip{x}{f}$，方程写成非齐次微分方程
\eq{
    \hat L_xu(x)=f(x),\quad
    \hat L_x:=\sum_n a_n(x)\pdv[n]{x}.
}
这里下标 $x$ 表示微分算符作用于变量 $x$。选定边界条件后，以 $\hat L^{-1}$ 表示相应的逆算符，则
\[
    u(x)=u_0(x)+\mel{x}{\hat L^{-1}}{f}=u_0(x)+\int\d{y}\mel{x}{\hat L^{-1}}{y}f(y),
\]
其中齐次解满足 $\hat L_xu_0(x)=0$。逆算符 $\hat L^{-1}$ 的积分核称为\textbf{Green 函数}：
\eq{
    G(x,y)
    :=\mel{x}{\hat L^{-1}}{y}
    = \hat L_x^{-1}\delta(x-y) .
}
所以 $\hat L_xG(x,y)=\delta(x-y)$。
$G(x,y)$ 描述 $y$ 处的非齐次源对 $x$ 处解的线性响应，一般不能解释为概率振幅。
若 $a_n$ 均为常数，$\hat L_x$ 具有平移不变性，平面波才是其本征函数。记
\eq{
    \hat L_x\e^{\i kx}=L(k)\e^{\i kx},\quad
    L(k):=\sum_n a_n(\i k)^n,
}
则 Fourier 变换给出
\eq{
    G(x,y)=\int\frac{\d k}{2\pi}
    \frac{\e^{\i k(x-y)}}{L(k)}.
}
若 $L(k)$ 在积分路径上有零点，还须规定绕过极点的方式；这正对应 Green 函数的边界条件。系数依赖 $x$ 时，平面波一般不再是本征函数，上述 Fourier 表达也不成立。
前文的自由预解算符
\eq{
    G_0(z):=(z-\hat H_0)^{-1},\quad
    z\notin\operatorname{spec}(\hat H_0),
}
也称\textbf{Green 算符}。其坐标表象为
\eq{
    G_0(\bm x,\bm x';z)
    :=\mel{\bm x}{G_0(z)}{\bm x'}
    = (z-\hat H_{0,\bm x})^{-1}
    \delta(\bm x-\bm x') ,
}
下标 $\bm x$ 同样表示哈氏量的坐标表象作用于第一个变量。若 $E$ 位于 $\hat H_0$ 的连续谱上，$E-\hat H_0$ 不可逆，必须取边界值 $G_0^\pm(E)=(E-\hat H_0\pm\i\epsilon)^{-1}$。
$+\i\epsilon,-\i\epsilon$ 分别规定出射和入射边界条件。

为简洁只写一个坐标自由度 $q$。
取 $t_b>t_1>t_a$。由演化算符的组合律并在 $t_1$ 插入位置完备关系，得到
\[
    \ip{q_b,t_b}{q_a,t_a}
    =\int\d{q_1}
    \ip{q_b,t_b}{q_1,t_1}\ip{q_1,t_1}{q_a,t_a}.
\]
即从初态到末态的振幅，等于经过所有可能中间态的振幅之和。这称为转移振幅的\textbf{Huygens 原理}，也是前文用时间切片构造路径积分的基础。
若在中间时刻插入坐标算符，则位置本征值带来一个额外因子 $q_1$：
\[
    \mel{q_b,t_b}{\hat q_H(t_1)}{q_a,t_a}
    =\int\d{q_1}
    \ip{q_b,t_b}{q_1,t_1}q_1\ip{q_1,t_1}{q_a,t_a}=\int_{q(t_a)=q_a}^{q(t_b)=q_b}\mathcal Dq\,
    q(t_1)\e^{\frac{\i}{\hbar}S[q]}.
\]
这里第一行的 $\hat q_H(t_1)$ 是算符，第二行的 $q(t_1)$ 则是某条路径在 $t_1$ 的函数值。反复插入完备关系可知，当 $t_b>t_n>\cdots>t_1>t_a$ 时，
\[
    \int_{q(t_a)=q_a}^{q(t_b)=q_b}\mathcal Dq\,
    q(t_n)\cdots q(t_1)\e^{\frac{\i}{\hbar}S[q]}
    =\mel{q_b,t_b}{\hat q_H(t_n)\cdots\hat q_H(t_1)}{q_a,t_a}.
\]
路径积分中的 $q(t_i)$ 是普通数，乘积次序可以任意；算符却未必对易，其次序由时间切片确定。因此对任意 $t_1,\ldots,t_n$，应写成
\eq{
    \int_{q(t_a)=q_a}^{q(t_b)=q_b}\mathcal Dq\,
    q(t_1)\cdots q(t_n)\e^{\frac{\i}{\hbar}S[q]}
    =\mel{q_b,t_b}{\Tord[\hat q_H(t_1)\cdots\hat q_H(t_n)]}{q_a,t_a}.
}
前文已定义时序符号 $\Tord$：它把时间较晚的算符放在左边。可见，路径积分天然对应时序乘积。
上式称为带固定端点的 $n$ 点\textbf{关联函数}。
在量子理论中，时序关联函数也常称 Green 函数；对自由的二次型体系，它确实与运动方程的逆核成正比。
除以无插入的 Feynman 核，可定义归一化关联函数
\eq{
    G_{ba}^{(n)}(t_1,\ldots,t_n)
    :=\frac{
    \mel{q_b,t_b}{\Tord[\hat q_H(t_1)\cdots\hat q_H(t_n)]}{q_a,t_a}}
    {\ip{q_b,t_b}{q_a,t_a}}
    =\frac{
    \int_{q_a}^{q_b}\mathcal Dq\,
    q(t_1)\cdots q(t_n)\e^{\frac{\i}{\hbar}S[q]}}
    {\int_{q_a}^{q_b}\mathcal Dq\,
    \e^{\frac{\i}{\hbar}S[q]}}.
}
它是在端点固定的所有路径上所作的归一化条件平均；由于实时路径的权重是复相位，这并非普通概率分布下的统计平均。$n=2$ 时称为两点关联函数，在自由体系中也常称传播子。

逐个插入算符并不方便。Schwinger 的做法是引入随时间变化的辅助函数 $J(t)$，称为\textbf{外源}，并令
\eq{
    S[q]\longrightarrow S_J[q]
    :=S[q]+\int_{t_a}^{t_b}\d{t}\,J(t)q(t).
}
外源既可描述真实作用，也可只作为计算工具，求导后令 $J=0$。有外源时的 Feynman 核为
\[
    \ip{q_b,t_b}{q_a,t_a}_J
    :=\int_{q(t_a)=q_a}^{q(t_b)=q_b}\mathcal Dq\,
    \e^{\frac{\i}{\hbar}S_J[q]}=\mel{q_b,t_b}{\Tord\exp[\frac{\i}{\hbar}
    \int_{t_a}^{t_b}\d{t}\,J(t)\hat q_H(t)]}{q_a,t_a}.
\]
第二式可将时序指数展开为级数，再使用上面的算符插入公式逐项验证。
位置本征态并不特殊。对任意初态 $\ket{\psi_i,t_a}$ 和末态 $\ket{\psi_f,t_b}$，同样有
\eq{
    \ip{\psi_f,t_b}{\psi_i,t_a}_J
    =\mel{\psi_f,t_b}{\Tord\exp[\frac{\i}{\hbar}
    \int_{t_a}^{t_b}\d{t}\,J(t)\hat q_H(t)]}{\psi_i,t_a}.
}
因此外源可以看成对体系施加的探针：它既能制备扰动，也能在末端探测响应。在散射问题中，这相当于用外源概括前文所说的粒子源和探测器，而无须重新指定每一种中间过程。

为了说明外源如何生成关联函数，先以变分关系定义\textbf{泛函导数}：
\eq{
    \delta F[J]
    =\int\d{t}\,\fdv{F[J]}{J(t)}\delta J(t),\quad
    \fdv{J(t')}{J(t)}=\delta(t-t').
}
因此
\eq{
    \fdv{}{J(t)}
    \exp[\frac{\i}{\hbar}\int\d{t'}\,J(t')q(t')]
    =\frac{\i}{\hbar}q(t)
    \exp[\frac{\i}{\hbar}\int\d{t'}\,J(t')q(t')].
}
每对 $J$ 作一次泛函微分，便从指数中取出一个坐标。定义归一化的端点\textbf{生成泛函}
\eq{
    Z_{ba}[J]:=\frac{\ip{q_b,t_b}{q_a,t_a}_J}
    {\ip{q_b,t_b}{q_a,t_a}},\quad Z_{ba}[0]=1,
}
于是
\eq{
    G_{ba}^{(n)}(t_1,\ldots,t_n)
    =\left(\frac{\hbar}{\i}\right)^n
    \left.\frac{\delta^nZ_{ba}[J]}
    {\delta J(t_1)\cdots\delta J(t_n)}\right|_{J=0}.
}

最常用的是基态关联函数。记外源插入为
\eq{
    \mathcal O_J:=\Tord\exp[\frac{\i}{\hbar}
    \int\d{t}\,J(t)\hat q_H(t)].
}
在外源作用区间的两侧各接上一段无外源演化，并插入能量本征态完备关系，可得
\[
    \mel{\chi_f}{\e^{-\frac{\i}{\hbar}\hat H T_+}
    \mathcal O_J
    \e^{-\frac{\i}{\hbar}\hat H T_-}}{\chi_i}=\sum_{m,n}
    \e^{-\frac{\i}{\hbar}(E_mT_++E_nT_-)}
    \ip{\chi_f}{m}\mel{m}{\mathcal O_J}{n}\ip{n}{\chi_i}.
\]
令 $T_\pm\to\infty(1-\i\varepsilon)$，其中 $\varepsilon>0$。每一项因而多出 $\e^{-\varepsilon(E_mT_++E_nT_-)/\hbar}$；只要边界态与基态不正交，激发态相对于能量最低的基态便指数衰减。再除以无外源的同一振幅，边界态重叠和基态演化相位均相消，最终只留下归一化的基态矩阵元。这就是 $\i\epsilon$ 的\textbf{基态投影}作用。

记基态 $\ket 0$，相应的基态到基态生成泛函为
\eq{
    Z[J]
    :=\frac{\mel{0}{\Tord\exp[\frac{\i}{\hbar}
    \int\d{t}\,J(t)\hat q_H(t)]}{0}}{\ip{0}}
    =\frac{\int\mathcal Dq\,
    \e^{\frac{\i}{\hbar}(S[q]+\int\d{t}\,Jq)}}
    {\int\mathcal Dq\,\e^{\frac{\i}{\hbar}S[q]}},\quad Z[0]=1,
}
其中积分区间及 $\i\epsilon$ 规定均隐含在记号中，也可把分母的倒数记为归一化常数 $\mathcal N$。对于二次型模型，还可在 Lagrange 量中加入 $+\i\varepsilon q^2/2$；它在路径积分权重中产生实的负指数，从而实现同样的收敛规定。它生成基态的时序关联函数：
\eq{
    G^{(n)}(t_1,\ldots,t_n)
    :=\mel{0}{\Tord[\hat q_H(t_1)\cdots\hat q_H(t_n)]}{0}
    =\left(\frac{\hbar}{\i}\right)^n
    \left.\frac{\delta^n Z[J]}
    {\delta J(t_1)\cdots\delta J(t_n)}\right|_{J=0}.
}
“生成”二字正是指 $Z[J]$ 的泛函 Taylor 系数给出所有 $n$ 点函数：
\eq{
    Z[J]=\sum_{n=0}^{\infty}\frac{1}{n!}
    \left(\frac{\i}{\hbar}\right)^n
    \int\d{t_1}\cdots\d{t_n}\,
    G^{(n)}(t_1,\ldots,t_n)
    J(t_1)\cdots J(t_n).
}
对于二次型作用量，前述 Gauss 路径积分可显式算出 $Z[J]$，而其二次项正由运动方程的逆核决定。这便解释了为何两点关联函数也被称为 Green 函数。

还可用\textbf{Wick 转动}把实时路径积分化为收敛性更直观的形式。令 $t=-\i\tau$，对 $L=m\dot q^2/2-V(q)$ 有
\eq{
    \frac{\i}{\hbar}S[q]\longrightarrow
    -\frac{1}{\hbar}S_E[q],\quad
    S_E[q]:=\int\d{\tau}\left[
    \frac{m}{2}\left(\dv{q}{\tau}\right)^2+V(q)\right].
}
相应的归一化 Euclid 生成泛函为
\eq{
    Z_E[J]
    :=\frac{\int\mathcal Dq\,
    \exp\{-\frac{1}{\hbar}[S_E[q]-\int\d{\tau}\,J(\tau)q(\tau)]\}}
    {\int\mathcal Dq\,\e^{-\frac{1}{\hbar}S_E[q]}},\quad
    Z_E[0]=1.
}
由于外源项现在以 $+\int Jq/\hbar$ 出现在指数中，Euclid 时间排序的关联函数满足
\eq{
    G_E^{(n)}(\tau_1,\ldots,\tau_n)
    =\hbar^n\left.
    \frac{\delta^n Z_E[J]}
    {\delta J(\tau_1)\cdots\delta J(\tau_n)}
    \right|_{J=0}.
}
Wick 转动在这里仍只是量子力学中的复时间方法：它改善路径积分的收敛性，并使长时间极限中的基态投影更加明显。

\section{简并态*}
前面讨论测量时，为了简化语言，我们常把一个本征值 $a_n$ 对应到一个本征态 $\ket{a_n}$。但这并非总是如此。若某个可观测量 $\hat A$ 的同一个本征值 $a$ 对应多个线性无关的本征态
\eq{
    \hat A\ket{a,\alpha}=a\ket{a,\alpha},\quad \alpha=1,\cdots,g,
}
则称谱值 $a$ 是 $g$ 重\textbf{简并}(degenerate)的。这里 $\alpha$ 不是新的测量值，只是在同一本征子空间中区分不同基矢的标签。可以取这些基矢正交归一：
\eq{
    \ip{a,\alpha}{a,\beta}=\delta_{\alpha\beta}.
}
于是对应本征子空间上的投影算符为
\eq{
    P_a=\sum_{\alpha=1}^{g}\op{a,\alpha}.
}
若 $\hat A$ 只有离散谱，则谱分解应写成
\eq{
    \hat A=\sum_a a P_a
    =
    \sum_a\sum_{\alpha=1}^{g_a}a\op{a,\alpha}.
}
测量 $\hat A$ 得到 $a$ 的概率不再是单个投影 $\op{a}$ 的平均值，而是整个本征子空间的投影：
\eq{
    P(a)=\frac{\ev{P_a}{\psi}}{\ip{\psi}}
    =
    \frac{1}{\ip{\psi}}\sum_{\alpha=1}^{g_a}
    \abs{\ip{a,\alpha}{\psi}}^2.
}
测量后态矢坍缩到这个子空间中：
\eq{
    \ket\psi\to
    \frac{P_a\ket\psi}{\sqrt{\ev{P_a}{\psi}}}.
}
只有当 $g_a=1$ 时，这才退化为前面写过的单一本征态 $\ket a$。

简并态中最需要注意的一点是：同一本征子空间内的基底并不唯一。若 $U_{\alpha\beta}$ 是一个 $g$ 维幺正矩阵，则
\eq{
    \ket{a,\alpha'}=\sum_{\beta=1}^{g}U_{\alpha\beta}\ket{a,\beta}
}
仍然是一组正交归一的 $\hat A$ 本征态，且本征值仍为 $a$。这说明只测量 $\hat A$ 无法区分同一本征子空间中的方向。若想把态进一步区分开，需要寻找另一个与 $\hat A$ 对易的可观测量 $\hat B$。若
\eq{
    [\hat A,\hat B]=0,
}
则 $\hat B$ 不会把 $\hat A$ 的本征子空间变到别的本征值空间中。证明很简单：若 $\hat A\ket{a,\alpha}=a\ket{a,\alpha}$，则
\eq{
    \hat A(\hat B\ket{a,\alpha})
    =
    \hat B\hat A\ket{a,\alpha}
    =
    a(\hat B\ket{a,\alpha}).
}
因此 $\hat B\ket{a,\alpha}$ 仍属于同一个 $a$ 的本征子空间。于是可在这个有限维子空间内继续对 $\hat B$ 对角化，用 $\hat B$ 的本征值补充标签。量子力学中常说的一组“完备对易可观测量”，本质上就是用足够多的对易算符把这些简并自由度完全标记出来。

哈氏量的简并尤其重要。设
\eq{
    \hat H\ket{n,\alpha}=E_n\ket{n,\alpha},\quad \alpha=1,\cdots,g_n.
}
若系统处于某个能量本征态，则 Schr\"odinger 方程给出
\eq{
    \ket{n,\alpha;t}
    =
    \e^{-\frac{\i}{\hbar}E_n t}\ket{n,\alpha}.
}
整体相位不影响任何测量概率，故所以这类态是定态。若能级简并，则任意线性叠加
\eq{
    \ket{\chi}=\sum_{\alpha=1}^{g_n}c_\alpha\ket{n,\alpha}
}
仍满足
\eq{
    \hat H\ket{\chi}=E_n\ket{\chi},
}
因此也是同一能量的定态。许多简并来自对称性：若某个幺正算符 $\hat U$ 与哈氏量对易，$[\hat U,\hat H]=0$，则
\eq{
    \hat H(\hat U\ket{n,\alpha})
    =
    \hat U\hat H\ket{n,\alpha}
    =
    E_n(\hat U\ket{n,\alpha}).
}
也就是说，$\hat U$ 作用后的态仍具有同一能量。如果 $\hat U\ket{n,\alpha}$ 与原态线性无关，就会产生简并。后面场论中，旋转、平移、内部对称性都常以这种方式组织能级或粒子态。

\section{定态微扰论*}

%% 微扰思维详细介绍

多数哈氏量无法严格求解。实际问题中常见的情形是：我们知道一个可解哈氏量$\hat H_0$ 的本征值和本征态，而真实哈氏量只是在它上面加了一个较小修正：
\eq{
    \hat H=\hat H_0+\lambda \hat V.
}
这里 $\hat V$ 称为\textbf{微扰}(perturbation)，$\lambda$ 是人为引入的无量纲参数，用来标记微扰阶数。计算完成后通常令 $\lambda=1$。若 $\hat V$ 不含时，就称为\textbf{定态微扰论}(time-independent perturbation theory)。它要解决的是本征值方程
\eq{
    \hat H\ket{n(\lambda)}
    =
    E_n(\lambda)\ket{n(\lambda)}.
}
物理动机很直接：若 $\lambda\hat V$ 相比 $\hat H_0$ 很小，则真实能级和真实本征态应当只是在未扰动结果附近发生小偏移。

假设能量和态矢都可按 $\lambda$ 展开：
\begin{align}
    E_n(\lambda)
    &=
    E_n^{(0)}
    +\lambda E_n^{(1)}
    +\lambda^2 E_n^{(2)}
    +\cdots,\\
    \ket{n(\lambda)}
    &=
    \ket{n^{(0)}}
    +\lambda\ket{n^{(1)}}
    +\lambda^2\ket{n^{(2)}}
    +\cdots.
\end{align}
其中上标 $(0)$ 表示未扰动问题：
\eq{
    \hat H_0\ket{n^{(0)}}=E_n^{(0)}\ket{n^{(0)}}.
}
将展开代入精确方程
\begin{align*}
    &(\hat H_0+\lambda\hat V)
    \left(
        \ket{n^{(0)}}+\lambda\ket{n^{(1)}}+\lambda^2\ket{n^{(2)}}+\cdots
    \right)\\
    =&
    \left(
        E_n^{(0)}+\lambda E_n^{(1)}+\lambda^2 E_n^{(2)}+\cdots
    \right)
    \left(
        \ket{n^{(0)}}+\lambda\ket{n^{(1)}}+\lambda^2\ket{n^{(2)}}+\cdots
    \right).
\end{align*}
比较 $\lambda$ 的同次幂，零阶给出原本征方程；一阶给出
\eq{
    \hat H_0\ket{n^{(1)}}+\hat V\ket{n^{(0)}}
    =
    E_n^{(0)}\ket{n^{(1)}}+E_n^{(1)}\ket{n^{(0)}},
}
即
\eq{
    (\hat H_0-E_n^{(0)})\ket{n^{(1)}}
    =
    (E_n^{(1)}-\hat V)\ket{n^{(0)}}.
}
二阶给出
\eq{
    \hat H_0\ket{n^{(2)}}+\hat V\ket{n^{(1)}}
    =
    E_n^{(0)}\ket{n^{(2)}}
    +E_n^{(1)}\ket{n^{(1)}}
    +E_n^{(2)}\ket{n^{(0)}},
}
即
\eq{
    (\hat H_0-E_n^{(0)})\ket{n^{(2)}}
    =
    (E_n^{(1)}-\hat V)\ket{n^{(1)}}
    +E_n^{(2)}\ket{n^{(0)}}.
}
微扰论的基本任务，就是逐阶解这些方程。

态矢本身还存在相位和归一化约定。非简并时，常采用中间归一化
\eq{
    \ip{n^{(0)}}{n(\lambda)}=1.
}
于是
\eq{
    \ip{n^{(0)}}{n^{(1)}}=
    \ip{n^{(0)}}{n^{(2)}}=\cdots=0.
}
这只是选定态矢沿 $\ket{n^{(0)}}$ 方向的分量，最终若需要严格归一化，可在计算结束后再归一化。

\subsection{非简并微扰法}

先假设未扰动能级 $E_n^{(0)}$ 非简并。取 $\hat H_0$ 的正交归一本征态
\eq{
    \hat H_0\ket{m^{(0)}}=E_m^{(0)}\ket{m^{(0)}},\quad
    \ip{m^{(0)}}{n^{(0)}}=\delta_{mn}.
}
将一阶方程左乘 $\bra{n^{(0)}}$，得到
\begin{align*}
    \mel{n^{(0)}}{\hat H_0}{n^{(1)}}
    +
    \mel{n^{(0)}}{\hat V}{n^{(0)}}
    &=
    E_n^{(0)}\ip{n^{(0)}}{n^{(1)}}
    +
    E_n^{(1)}\ip{n^{(0)}}{n^{(0)}}.
\end{align*}
由于 $\hat H_0$ 是 Hermite 的，且 $\bra{n^{(0)}}\hat H_0=E_n^{(0)}\bra{n^{(0)}}$，上式左边第一项为 $E_n^{(0)}\ip{n^{(0)}}{n^{(1)}}$，与右边相同项抵消，故
\eq{
    \tcbhighmath{E_n^{(1)}=\mel{n^{(0)}}{\hat V}{n^{(0)}}.}
}
这说明一阶能量修正就是微扰哈氏量在原态上的平均值。

为了求态矢的一阶修正，将 $\ket{n^{(1)}}$ 展开到未扰动本征态基底：
\eq{
    \ket{n^{(1)}}=\sum_m c_m^{(1)}\ket{m^{(0)}}.
}
中间归一化给出 $c_n^{(1)}=0$。再将一阶方程左乘 $\bra{m^{(0)}}$，其中 $m\neq n$，得
\eq{
    E_m^{(0)}c_m^{(1)}
    +
    \mel{m^{(0)}}{\hat V}{n^{(0)}}
    =
    E_n^{(0)}c_m^{(1)}.
}
因此
\eq{
    c_m^{(1)}
    =
    \frac{\mel{m^{(0)}}{\hat V}{n^{(0)}}}
    {E_n^{(0)}-E_m^{(0)}}.
}
于是
\eq{
    \tcbhighmath{
    \ket{n^{(1)}}
    =
    \sum_{m\neq n}
    \ket{m^{(0)}}
    \frac{\mel{m^{(0)}}{\hat V}{n^{(0)}}}
    {E_n^{(0)}-E_m^{(0)}}.}
}
这个公式也解释了微扰论的适用条件：若 $\hat V$ 的矩阵元很小，且能级差 $E_n^{(0)}-E_m^{(0)}$ 不太小，则态的混合很弱；若分母接近零，非简并微扰论就会失效。

二阶能量修正可由二阶方程得到。左乘 $\bra{n^{(0)}}$：
\begin{align*}
    \mel{n^{(0)}}{\hat H_0}{n^{(2)}}
    +
    \mel{n^{(0)}}{\hat V}{n^{(1)}}
    &=
    E_n^{(0)}\ip{n^{(0)}}{n^{(2)}}
    +
    E_n^{(1)}\ip{n^{(0)}}{n^{(1)}}
    +
    E_n^{(2)}.
\end{align*}
第一项仍与右边的 $E_n^{(0)}\ip{n^{(0)}}{n^{(2)}}$ 抵消，而中间归一化使 $\ip{n^{(0)}}{n^{(1)}}=0$，故
\eq{
    E_n^{(2)}
    =
    \mel{n^{(0)}}{\hat V}{n^{(1)}}.
}
代入 $\ket{n^{(1)}}$ 得
\eq{
    \tcbhighmath{
    E_n^{(2)}
    =
    \sum_{m\neq n}
    \frac{
    \abs{\mel{m^{(0)}}{\hat V}{n^{(0)}}}^2}
    {E_n^{(0)}-E_m^{(0)}}.}
}
因此非简并定态微扰论给出
\eq{
    E_n
    =
    E_n^{(0)}
    +
    \lambda\mel{n^{(0)}}{\hat V}{n^{(0)}}
    +
    \lambda^2
    \sum_{m\neq n}
    \frac{
    \abs{\mel{m^{(0)}}{\hat V}{n^{(0)}}}^2}
    {E_n^{(0)}-E_m^{(0)}}
    +\cdots.
}
若需要态矢到一阶，则
\eq{
    \ket{n}
    =
    \ket{n^{(0)}}
    +
    \lambda
    \sum_{m\neq n}
    \ket{m^{(0)}}
    \frac{\mel{m^{(0)}}{\hat V}{n^{(0)}}}
    {E_n^{(0)}-E_m^{(0)}}
    +\cdots.
}

\subsection{简并微扰法}

若 $E_n^{(0)}$ 是简并能级，上面的非简并公式立刻出现问题：同一能级内存在 $m\neq n$ 但 $E_m^{(0)}=E_n^{(0)}$，分母为零。说明物理假设有错。简并子空间中的任意线性组合都是同一零阶能量的本征态，微扰一打开，真实本征态到底接近哪一个线性组合，需要由微扰本身决定。

设简并子空间为
\eq{
    \Hilbert_n
    =
    \operatorname{span}\left\{\ket{n,\alpha^{(0)}}:\alpha=1,\cdots,g\right\},
}
并有
\eq{
    \hat H_0\ket{n,\alpha^{(0)}}=E_n^{(0)}\ket{n,\alpha^{(0)}}.
}
真实态的零阶部分不能预先指定为某个 $\ket{n,\alpha^{(0)}}$，而应写成一般线性组合
\eq{
    \ket{\chi^{(0)}}=\sum_{\alpha=1}^{g}c_\alpha\ket{n,\alpha^{(0)}}.
}
一阶方程为
\eq{
    (\hat H_0-E_n^{(0)})\ket{\chi^{(1)}}
    =
    (E^{(1)}-\hat V)\ket{\chi^{(0)}}.
}
将其左乘 $\bra{n,\alpha^{(0)}}$。由于
\[
    \bra{n,\alpha^{(0)}}(\hat H_0-E_n^{(0)})=0,
\]
得到
\eq{
    \mel{n,\alpha^{(0)}}{\hat V}{\chi^{(0)}}
    =
    E^{(1)}\ip{n,\alpha^{(0)}}{\chi^{(0)}}.
}
代入 $\ket{\chi^{(0)}}=\sum_\beta c_\beta\ket{n,\beta^{(0)}}$，得
\eq{
    \sum_{\beta=1}^{g}
    V_{\alpha\beta}c_\beta
    =
    E^{(1)}c_\alpha,
    \quad
    V_{\alpha\beta}
    :=
    \mel{n,\alpha^{(0)}}{\hat V}{n,\beta^{(0)}}.
}
这就是一个 $g$ 维矩阵本征值问题。结论是：\textit{简并微扰论第一步并非直接套非简并公式，而是在简并子空间内对角化微扰矩阵 $V_{\alpha\beta}$。} 它的本征值就是一阶能量修正，本征向量给出正确的零阶线性组合。

设微扰矩阵的本征向量记为 $c_\alpha^{(r)}$，本征值记为 $v_r$：
\eq{
    \sum_{\beta=1}^{g}
    V_{\alpha\beta}c_\beta^{(r)}
    =
    v_r c_\alpha^{(r)}.
}
则相应的零阶态应选为
\eq{
    \ket{n,r^{(0)}}
    =
    \sum_{\alpha=1}^{g}
    c_\alpha^{(r)}\ket{n,\alpha^{(0)}},
}
并有
\eq{
    E_{n,r}=E_n^{(0)}+\lambda v_r+\cdots.
}
若不同 $v_r$ 彼此不同，原来的 $g$ 重简并就在一阶被完全解除。若某些 $v_r$ 仍相同，则说明微扰在这部分子空间中仍保留简并，需要继续在剩余简并子空间内考察更高阶修正，或寻找更多对易可观测量。

接着求态矢混入简并子空间外的部分。定义投影算符
\eq{
    P=\sum_{\alpha=1}^{g}\op{n,\alpha^{(0)}},\quad Q=1-P.
}
选定上面已经对角化的某个态 $\ket{n,r^{(0)}}$，并取约定 $P\ket{n,r^{(1)}}=0$，即一阶修正只写出流到其他能级的部分。将一阶方程投影到 $Q$ 子空间，并在 $\hat H_0$ 的其他本征态 $\ket{m,\beta^{(0)}}$ 上展开，其中 $E_m^{(0)}\neq E_n^{(0)}$，可得
\eq{
    \ket{n,r^{(1)}}
    =
    \sum_{m\neq n}\sum_{\beta}
    \ket{m,\beta^{(0)}}
    \frac{
    \mel{m,\beta^{(0)}}{\hat V}{n,r^{(0)}}
    }
    {E_n^{(0)}-E_m^{(0)}}.
}
这里的求和 $m\neq n$ 表示排除整个原简并能级，而不是只排除某一个态。可见一旦先在简并子空间内选对基底，子空间外的修正又恢复成类似非简并微扰论的形式。

二阶修正也可写成简洁的有效矩阵。若一阶已经完全解除简并，则某个态 $\ket{n,r^{(0)}}$ 的二阶能量为
\eq{
    E_{n,r}^{(2)}
    =
    \sum_{m\neq n}\sum_{\beta}
    \frac{
    \abs{\mel{m,\beta^{(0)}}{\hat V}{n,r^{(0)}}}^2
    }
    {E_n^{(0)}-E_m^{(0)}}.
}
若一阶仍有剩余简并，则不能只取对角元，而应在剩余简并子空间内继续对角化二阶有效矩阵
\eq{
    W^{(2)}_{rs}
    =
    \sum_{m\neq n}\sum_{\beta}
    \frac{
    \mel{n,r^{(0)}}{\hat V}{m,\beta^{(0)}}
    \mel{m,\beta^{(0)}}{\hat V}{n,s^{(0)}}
    }
    {E_n^{(0)}-E_m^{(0)}}.
}
它的本征值给出二阶能量修正，它的本征向量进一步决定正确的零阶线性组合。由此可见，简并微扰法的逻辑始终是：先在简并子空间内寻找能被微扰选中的正确基底，再计算与其他能级之间的混合。
